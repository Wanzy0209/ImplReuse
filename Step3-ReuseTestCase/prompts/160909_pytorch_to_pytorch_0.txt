### 🐛 Describe the bug

Hi torch.compile group,

I am running some tests using PrivateUse1 with torch.compile, and see meta device tensors called on PrivateUse1 ops.

The code is essentially 

```
def my_backend():
    // my compile logic

model = Model()
compiled = torch.compile(model.to("PrivateUse1"), backend=my_backend)
result = compiled(data.to('PrivateUse1'))
```

```
repeat_interleave(*(FakeTensor(..., device='PrivateUse1', size=(1, 8, 3, 128), grad_fn=<AddBackward0>), 2), **{'dim': 1}): got RuntimeError('flatten(): flatten: Dispatch failed: storage is not on the custom PrivateUse1 device. Got: meta')
```
