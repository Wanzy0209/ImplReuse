Issue ID: 159974
Title: Segmentation fault when using torch.compile with PyTorch 2.8.0 XPU on Intel ARC A770
Bug Description:
### 🐛 Describe the bug

Using any torch.compile after PyTorch 2.8.0 (and 2.9 nightlies) results in Segmentation fault with Intel ARC A770 / XPU
Provided code and more complex torch.compile works fine with PyTorch 2.7.1+xpu, so this is a regression in 2.8.

```py
import torch

def addcmul_func(x, y, z):
    return x + (y * z)


x = torch.randn(128).to("xpu")
y = torch.randn(128).to("xpu")
z = torch.randn(128).to("xpu")

out = addcmul_func(x,y,z)
print("eager mode passed")

addcmul_func_compiled = torch.compile(addcmul_func)
out = addcmul_func_compiled(x,y,z)
print("torch.compile passed")
```

### Error logs

```
(venv) disty:~ $ python compile.py 
eager mode passed
Segmentation fault         (core dumped)
```
