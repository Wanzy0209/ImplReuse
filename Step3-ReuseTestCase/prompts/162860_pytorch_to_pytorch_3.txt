Issue ID: 162860
Title: [dynamo] add more debug information to LazyVariableTrackers
Bug Description:
LazyVariableTracker logs in `TORCH_LOGS=trace_bytecode` are opaque and don't provide much context.

It would be good to include information such as:
- the type of the example value
- If the variable has been realized, output the realized variable as well

For example,
```python
import torch


def inner(x):
    return x + 1


@torch.compile(backend="eager")
def fn(x):
    x = inner(x)
    return inner(x)


fn(torch.ones(3))
```
