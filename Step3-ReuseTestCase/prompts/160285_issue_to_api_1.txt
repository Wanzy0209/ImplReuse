Title: Wrong-size gradients in Expert Parallel MoE
Bug Description:
### 🐛 Describe the bug

### Repro

[test_moe_gradients.txt](https://github.com/user-attachments/files/21707913/test_moe_gradients.txt)
[torch_moe.txt](https://github.com/user-attachments/files/21707912/torch_moe.txt)

Install torchtitan on your system (`pip install torchtitan`). Rename the file extensions to .py. Run with `OMP_NUM_THREADS=1 torchrun --nproc_per_node=2 test_moe_gradients.py`.

The observed behavior is that the gradients for MoE layers are doubled with EP=2.

Use of TorchGroupedExperts in a non-testcase environment shows that loss curves are equivalent even with the doubled gradients; each MoE gradient is exactly 2x in size.

### Observables

This testcase replicates torchtitan's EP+MoE layer by copying code directly into `torch_moe.py`. Possibilities:
1. torch has a bug (perhaps in the distributed parts)
2. torchtitan has a bug. I don't see it though.

~3. my replication of torchtitan has a bug.~ I checked, vanilla torchtitan has the same bug.
