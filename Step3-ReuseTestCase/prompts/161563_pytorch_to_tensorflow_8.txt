Issue ID: 161563
Title: [export] "Current active mode not registered" when exporting vmap
Bug Description:
### 🐛 Describe the bug

When exporting gemma-3-270m-it with torch.export, I got the error `AssertionError: Current active mode <torch.fx.experimental.proxy_tensor.ProxyTorchDispatchMode object at 0x730aa6fcecf0> not registered`.

```py
import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

tokenizer = AutoTokenizer.from_pretrained("google/gemma-3-270m-it")
model = AutoModelForCausalLM.from_pretrained("google/gemma-3-270m-it")


messages = [
    {"role": "user", "content": "Who are you?"},
]

inputs = tokenizer.apply_chat_template(
    messages,
    add_generation_prompt=True,
    tokenize=True,
    return_dict=True,
    return_tensors="pt",
).to(model.device)


example_inputs = (inputs["input_ids"], inputs["attention_mask"])

ep = torch.export.export(model, example_inputs)
```
