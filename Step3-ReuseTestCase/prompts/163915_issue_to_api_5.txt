Issue ID: 163915
Title: nvshmem triton kernels IMA silently
Bug Description:
### 🐛 Describe the bug

### Repro
```
import torch.symm_mem._nvshmem_triton as nvshmem

@triton.jit
def foo(...):
    nvshmem.get(...)

def run():
    nvshmem.enable_triton()
    foo[(1, )]()
```

### Cause
The previous `enable_triton` UI requires the user-defined Triton kernel have a "nvshmem" in its name. But this requirement is in the doc and sometimes the user does not notice it.
If users did not do so, the kernel would miss the NVSHMEM init, and silently hit CUDA IMA.
