Issue ID: 162756
Title: torch.compile fails with NameError when helper functions are required and combo_kernels enabled
Bug Description:
### 🐛 Describe the bug

When `torch._inductor.config.combo_kernels = True` is enabled, compilation fails with `NameError` for Triton helper functions (e.g., `_triton_helper_fn_add0`) when operations that require helper functions (like `cumsum`) are combined into combo kernels.

repro:
```python
import torch
torch._inductor.config.combo_kernels = True

@torch.compile
def fn(x, y, z):
    return x.sum(1), y.mean(1), z.cumsum(1)

inps = (
    torch.rand(16, 128, device="cuda"),
    torch.rand(32, 128, device="cuda"),
    torch.rand(32, 256, device="cuda"),
)

fn(*inps)
```
