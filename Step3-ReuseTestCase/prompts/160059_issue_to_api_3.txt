Issue ID: 160059
Title: torch.jit.script fails with 'undefined value' error when module has @torch.compiler.disable decorator (regression in 2.8.0)
Bug Description:
### 🐛 Describe the bug

# Description

`torch.jit.script` fails with an "undefined value" error when attempting to script a module that has a `@torch.compiler.disable` decorator on its forward method.
This appears to be a regression introduced in PyTorch 2.8.0, as the same code worked correctly in version 2.7.0.

# Reproduction Steps

Minimal reproducible example:

```python
import torch
from torch import nn


def inverse_sigmoid(x: torch.Tensor, eps: float = 1e-5) -> torch.Tensor:
    x = x.clamp(min=0, max=1)
    x1 = x.clamp(min=eps)
    x2 = (1 - x).clamp(min=eps)

    return torch.log(x1 / x2)


class Model(nn.Module):
    @torch.compiler.disable(recursive=False)  # type: ignore[misc]
    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = inverse_sigmoid(x)
        return x


n = Model()
torch.jit.script(n)
```
