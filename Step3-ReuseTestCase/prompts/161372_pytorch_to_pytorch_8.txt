Title: torch.compile regression in 2.8.0
Bug Description:
### 🐛 Describe the bug

Hi there,
I've been a fan of `torch.compile` as it helped to speed up my code substantially in most cases. However, some of it broke in 2.8.0. 

For instance, I have this pure PyTorch implementation of an LLM that is geared towards code readability, which got an ~2x speed-up on CPU and ~4x speed-up on GPU when compiled in PyTorch 2.6 and 2.7.1
