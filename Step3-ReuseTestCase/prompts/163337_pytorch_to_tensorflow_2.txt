Issue ID: 163337
Title: Compilation error withstatic_castfromfloatto__halfwhen building PyTorch extension with rocWMMA on ROCm
Bug Description:
### 🐛 Describe the bug


When attempting to build a PyTorch C++ extension that utilizes rocWMMA kernels on a ROCm-based system (AMD GPU), the compilation fails. The error message indicates a problem with `static_cast` from `float` to `rocwmma::hfloat16_t` (which is an alias for `__half`). This issue seems to originate from within the rocWMMA header files (`vector.hpp`) when they are included and compiled in the context of a PyTorch extension.

The compilation command is executed by `torch.utils.cpp_extension.load`. The error suggests that the compiler cannot find a suitable constructor to convert a `float` literal (like `0.0f`) to a `__half` type, which is required by some rocWMMA vector initialization templates.

Here is the core error message from the build process:
```
/opt/rocm-7.0.1/include/rocwmma/internal/layout/../vector.hpp:446:1148: error: no matching conversion for static_cast from 'float' to 'rocwmma::hfloat16_t' (aka '__half')
  446 | ... constexpr explicit HIP_vector_base(rocwmma::hfloat16_t val) noexcept : HIP_vector_base(rocwmma::detail::template bCast<HIP_vector_base>( static_cast<rocwmma::hfloat16_t>(0.0f), rocwmma::detail::Seq<1>{})) { data[0] = val; } ...
      |
...
