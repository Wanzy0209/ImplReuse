Title: Remove redundant dtype conversion in scaled_dot_product_attention docstring example
Bug Description:
### 🐛 Describe the bug

**🐛 Describe the bug**

The docstring example in `scaled_dot_product_attention` contains a redundant and ineffective dtype conversion.

**Code location**: 
`torch/nn/functional.py` - in the docstring of `scaled_dot_product_attention`
https://github.com/pytorch/pytorch/blob/3d406429b0ac472b65d944c0634203ac1548a7c9/torch/nn/functional.py#L5821-L5826

**Issue**:
```python
attn_bias = torch.zeros(L, S, dtype=query.dtype, device=query.device)  # Already query.dtype
if is_causal:
    # ...
    attn_bias.masked_fill_(temp_mask.logical_not(), float("-inf"))
    attn_bias.to(query.dtype)  # Redundant! Already query.dtype, and result not assigned
```

**Problems**:
1. `attn_bias` is already created with `dtype=query.dtype`
2. `masked_fill_` is an in-place operation that doesn't change dtype
3. `attn_bias.to(query.dtype)` is redundant since it's already the correct dtype
4. The result of `.to()` is not assigned back, making it completely ineffective

**Expected fix**:
Remove the line `attn_bias.to(query.dtype)` entirely.
