Issue ID: 167927
Title: torch.compile(fullgraph=True) should accept torch.compiler.disable
Bug Description:
### 🐛 Describe the bug

Feel free to change to a feature request, in case you don't consider this a bug.

`torch.compiler.disable` is intended to exclude functions from compilation, for example when they're known to cause issues.
`torch.compile(fullgraph=True)` is intended to avoid unintentional graph breaks. you want to see errors instead of silent graph breaks, so you can fix your graph breaks.

but `torch.compiler.disable` is an intentional one. this should not be an error, so you can combine these two useful features.
current best workaround is to use `fullgraph=False` and check with torch profiler whether it compiled what you wanted compiled. not ideal.
