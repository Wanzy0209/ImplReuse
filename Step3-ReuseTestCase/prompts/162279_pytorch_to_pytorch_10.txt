Issue ID: 162279
Title: torch.export incorrect output shape when exporting two models
Bug Description:
### 🐛 Describe the bug

The following code provides the setup. Basically we defined two models, which run any.dims, one with an empty dim list, and the other with a null dim list. And then we have a "process" function to run eager mode and export

```python
import torch
import torch.nn as nn

class AnyDimsModelEmpty(nn.Module):
    def __init__(self):
        super(AnyDimsModelEmpty, self).__init__()

    def forward(self, x):
        print('input shape:', x.shape)
        y = torch.ops.aten.any.dims(x, [], False)
        print('output shape:', y.shape)
        return y

class AnyDimsModelNull(nn.Module):
    def __init__(self):
        super(AnyDimsModelNull, self).__init__()

    def forward(self, x):
        print('input shape:', x.shape)
        y = torch.ops.aten.any.dims(x, None, False)
        print('output shape:', y.shape)
        return y

def process(model, x):
    print('model:', model)
    print('running eager mode...')
    model(x)
    print('exporting...')
    torch.export.export(model, (x,))
    print()
```

If we only process one model, then everything is fine, but if we process both models, one after the other, the output shape during export is incorrect for the second model. It doesn't matter which one we process first and which one we process second. I think this must be related to some sort of caching?
