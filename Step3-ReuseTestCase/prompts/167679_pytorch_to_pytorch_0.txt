Issue ID: 167679
Title: MPS built but not available on macOS 26 (Tahoe), PyTorch 2.9.1 / 2.10 nightly
Bug Description:
OS: macOS 26.0 (Tahoe), Apple Silicon
Python: 3.11.14 (conda)
PyTorch: 2.9.1 (stable), 2.10.0.dev20251112 (nightly)
Install: CPU wheels from https://download.pytorch.org/whl/cpu, arm64 build

Repro:

    conda create -n mps_torch python=3.11 -y
    conda activate mps_torch
    python -m pip install torch torchvision torchaudio \
      --index-url https://download.pytorch.org/whl/cpu

    python - << 'EOF'
    import sys, platform, torch
    print("Python:", sys.version)
    print("Executable:", sys.executable)
    print("PyTorch:", torch.__version__)
    print("macOS:", platform.mac_ver()[0])
    print("platform:", platform.platform())
    print("arch:", platform.machine())
    print("is_macos_or_newer(14,0):",
          getattr(torch.backends.mps, "is_macos_or_newer", lambda *a: "no-func")(14,0))
    print("MPS built?:", torch.backends.mps.is_built())
    print("MPS available?:", torch.backends.mps.is_available())
    EOF

Output:

    PyTorch: 2.9.1 (or 2.10.0.dev20251112)
    macOS: 26.0
    platform: macOS-26.0-arm64-arm-64bit
    arch: arm64
    is_macos_or_newer(14,0): True
    MPS built?: True
    MPS available?: False

Expected: `MPS available?: True` on Apple Silicon under Tahoe.
