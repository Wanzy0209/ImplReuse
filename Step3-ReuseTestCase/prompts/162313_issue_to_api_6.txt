Issue ID: 162313
Title: [dynamo] KeyError in resume function creation in Python 3.11+
Bug Description:
Minimal repro:

```python
import torch

flag = True


@torch.compile(backend="eager")
def fn(x):
    x = x + 1
    torch._dynamo.graph_break()
    x = x + 2
    if flag:
        with torch.no_grad():
            torch._dynamo.graph_break()
    else:
        with torch.no_grad():
            torch._dynamo.graph_break()
    return x + 4


fn(torch.ones(3))
flag = False
fn(torch.ones(3))
```

This is because we're incorrectly using `meta.block_target_offset_remap` in resume_execution.py.
