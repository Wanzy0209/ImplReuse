Issue ID: 162860
Title: [dynamo] add more debug information to LazyVariableTrackers
Bug Description:
LazyVariableTracker logs in `TORCH_LOGS=trace_bytecode` are opaque and don't provide much context.

It would be good to include information such as:
- the type of the example value
- If the variable has been realized, output the realized variable as well

For example,
```python
import torch


def inner(x):
    return x + 1


@torch.compile(backend="eager")
def fn(x):
    x = inner(x)
    return inner(x)


fn(torch.ones(3))
```

Today, `TORCH_LOGS=trace_bytecode` gives:
```
TRACE RESUME 0 []
TRACE LOAD_GLOBAL inner []
TRACE LOAD_FAST x [LazyVariableTracker(), NullVariable]
TRACE CALL 1 [LazyVariableTracker(), NullVariable, LazyVariableTracker()]
TRACE RESUME 0 []
TRACE LOAD_FAST x []
TRACE LOAD_CONST 1 [TensorVariable()]
TRACE BINARY_OP 0 [TensorVariable(), ConstantVariable(int: 1)]
TRACE RETURN_VALUE None [TensorVariable()]
TRACE STORE_FAST x [TensorVariable()]
TRACE LOAD_GLOBAL inner []
TRACE LOAD_FAST x [LazyVariableTracker(), NullVariable]
TRACE CALL 1 [LazyVariableTracker(), NullVariable, TensorVariable()]
TRACE RESUME 0 []
