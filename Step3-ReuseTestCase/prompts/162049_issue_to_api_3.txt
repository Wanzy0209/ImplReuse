Issue ID: 162049
Title: NestedTensor: max_dim / min_dim not working for integer tensors
Bug Description:
### 🐛 Describe the bug

# Bug Description

Calling `.max(dim=...)`. `.min(dim=...)`, `.argmax(dim=...)`, or `.argmin(dim=...)` on a nested jagged tensor *with integer datatype* raises an error. The functions are supported, however, for floating point types.

# Cause

The implementation accesses `torch.finfo` to determine the minimum value for the given type. For integral types, `torch.iinfo` would have to be used instead.

# Minimal Reproducing Example

```python
import torch

x = torch.nested.nested_tensor(
    [torch.arange(0, n) for n in (10, 20, 30)],
    layout=torch.jagged,
)
print(x.max(dim=1).values)
```

## Expected Result

```
tensor([9, 19, 29])
```
