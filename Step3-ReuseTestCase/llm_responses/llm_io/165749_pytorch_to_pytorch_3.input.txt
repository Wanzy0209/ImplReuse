Issue ID: 165749
Title: Backward pass failure fornn.Conv2dwithweight_normandtorch.compile
Bug Description:
### 🐛 Describe the bug

I encountered a failure when training a convolutional model with weight normalization and `torch.compile`.
Here is the minimal reproducer:

```py
import torch
from torch import nn
from torch.nn.utils.parametrizations import weight_norm
from torch.optim import SGD

if __name__ == "__main__":
    d = 65
    x = torch.randn((1, 2, 32, 32)).cuda()
    model = torch.compile(weight_norm(nn.Conv2d(2, d, 2)).train().cuda())
    opt = SGD(model.parameters())
    for _ in range(1000):
        model(x).mean().backward()
        opt.step()
        opt.zero_grad()
```

It fails with: `torch._inductor.exc.InductorError: RuntimeError: saved_v must be contiguous`, which seems to be raised during the backward pass: https://github.com/pytorch/pytorch/blob/5d4da26ed067d2d70102f30967f1b09f8fb7018a/aten/src/ATen/native/cuda/WeightNorm.cu#L437

This error is not raised if I remove `torch.compile` or if `d <= 64`.
I also can't reproduce this behavior with either `nn.Linear` or `nn.Conv1d` instead of `nn.Conv2d`.
