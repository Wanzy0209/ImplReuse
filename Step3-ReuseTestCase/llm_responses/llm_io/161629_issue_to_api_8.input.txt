Issue ID: 161629
Title: remove a newly added cpp_ext warning
Bug Description:
a new warning appeared in pt-2.8.0:
```
[rank7]:W0827 05:24:55.683000 68843 site-packages/torch/utils/cpp_extension.py:2425] TORCH_CUDA_ARCH_LIST is not set, all archs for visible cards are included for compilation.
[rank7]:W0827 05:24:55.683000 68843 site-packages/torch/utils/cpp_extension.py:2425] If this is not desired, please set os.environ['TORCH_CUDA_ARCH_LIST'] to specific architectures.
```
**which gets repeated on all ranks w/ multi-gpu torch.dist.**

As discussed at https://pytorch.slack.com/archives/C3PDTEV8E/p1756272598961369 this warning:
1. should be `torch.dist`-aware if it prints anything at all (i.e. print only on rank0)
2. unless the logging level is set to DEBUG/INFO it shouldn't be printed at all
3. the message could be improved to telling the user what it sets the env var to, e.g. "setting TORCH_CUDA_ARCH_LIST=9.0,10.0 since TORCH_CUDA_ARCH_LIST hasn't been set and these are the gpu architectures visible to torch"
