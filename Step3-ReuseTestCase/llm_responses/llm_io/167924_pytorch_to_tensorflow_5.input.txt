Issue ID: 167924
Title: Crash on MPS when using repeat_interleave with sliced tensor
Bug Description:
### 🐛 Describe the bug

Using repeat_interleave with a tensor that has been sliced to a non-prefix causes a segfault on MPS. See below minimal reproduction.

I have done some preliminary investigation, but I'm not familiar enough with the codebase to be able to identify the root cause.

```python
import torch

counts = torch.tensor([0, 1, 0], device="mps")
data = torch.arange(2, device="mps")
data.repeat_interleave(counts[1:3], dim=0)
```
