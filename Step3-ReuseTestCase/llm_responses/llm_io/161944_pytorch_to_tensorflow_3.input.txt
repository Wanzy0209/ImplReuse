Title: [compile] Inductor uses fast math for exp
Bug Description:
### 🐛 Describe the bug

```
import torch
torch.set_default_device('cuda') 

inp = torch.randn(8192)
func = torch.exp
out1 = func(inp)

out3_high = func(inp.to(torch.float64))
```
