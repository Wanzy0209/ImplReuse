Issue ID: 165649
Title: torch.fmodcrashes on integer tensors when dividend is the minimum representable value and divisor is -1
Bug Description:
### 🐛 Describe the bug

Calling torch.fmod on int64 tensors crashes the Python process (segfault / arithmetic exception) when any element satisfies a == INT64_MIN and b == -1.
```python
import torch

dividend = torch.full((2, 3), torch.iinfo(torch.int64).min, dtype=torch.int64, device='cpu')
divisor = torch.full((3,), -1, dtype=torch.int64, device='cpu')

print("Dividend tensor:", dividend)
print("Divisor tensor:", divisor)

result = torch.fmod(dividend, divisor)
print("Result:", result)
```


### Versions

```
PyTorch version: 2.5.1+cu124
```
