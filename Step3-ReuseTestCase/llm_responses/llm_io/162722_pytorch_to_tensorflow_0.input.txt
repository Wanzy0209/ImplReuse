Title: Severe Numerical Inconsistency with torch.compile() on Transformer Model
Bug Description:
### 🐛 Describe the bug

 Description
When using torch.compile() on a custom Transformer-based model, we observe severe numerical inconsistencies that render the compiled model unusable. The differences are far beyond expected Triton RNG variations and indicate a fundamental issue with the compilation process.
