Issue ID: 162480
Title: missing float handling in function rebind_unbacked() (torch.fx.experimental.symbolic_shapes.py) for AOTInductor
Bug Description:
### 🐛 Describe the bug

I encounter a AOTInductor compile bug, which is reprted in [Torch AOTInductor Ahead-Of-Time Compilation Compile Fail](https://github.com/opendatalab/DocLayout-YOLO/issues/177).
By debuging, I found that the problem is here.
https://github.com/pytorch/pytorch/blob/main/torch/fx/experimental/symbolic_shapes.py#L597
After adding  the `float` handling, the bug is fixed.
```
# insert after https://github.com/pytorch/pytorch/blob/main/torch/fx/experimental/symbolic_shapes.py#L603
            if isinstance(u1, float):
                log.info(
                    "rebind_unbacked: discard %s %s %s -> %s",
                    n.target,
                    raw_u0,
                    path,
                    u1,
                )
                continue
```
