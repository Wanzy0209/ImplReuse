Issue ID: 164301
Title: torch.compile regression: mxfp8 quantization along rows
Bug Description:
### 🐛 Describe the bug

## Summary
- Sometime between 09/12 and 09/30, torch.compile has had a major regression in the performance of inductor codgen for mxfp8 quantization along rows- i.e., (1 x block_size) scaling granularity

## Repro

1. Use machine with B200 GPUs and cuda 12.8
2. Install torch nightly build for cuda 12.8: `pip3 install --pre torch --index-url https://download.pytorch.org/whl/nightly/cu128` 
2. Clone torchao `git clone git@github.com:pytorch/ao.git`
3. Run benchmark: `cd ao/benchmarks/mx_formats`
4. `CUDA_VISIBLE_DEVICES=7 python cast_bench.py --mode dim0_mxfp8_floor`
5. See ~1485gbps:
```
(torch) [danvm@devgpu007.snb3 ~/ao/benchmarks/mx_formats (mx-a2a-2)]$ CUDA_VISIBLE_DEVICES=7 python cast_bench.py --mode dim0_mxfp8_floor
