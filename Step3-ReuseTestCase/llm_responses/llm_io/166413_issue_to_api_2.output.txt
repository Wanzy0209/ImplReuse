```python
# pyright: strict
import tensorflow as tf
from typing import reveal_type

# The original issue (torch.no_grad) involved a decorator that obscured the type of a function
# because the underlying class implementation (__new__) was untyped.
# This test checks if the similar API (tf.keras.initializers.HeNormal), which is also a class
# wrapping a specific behavior, maintains correct type information.

# Instantiate the initializer
# We check if the class instantiation is typed correctly (analogous to the decorator factory)
initializer = tf.keras.initializers.HeNormal(seed=42)
reveal_type(initializer)

# Call the initializer
# We check if the callable instance preserves type information (analogous to the decorated function)
# Initializers are callables that return Tensors.
weights = initializer(shape=(2, 2))
reveal_type(weights)
```
