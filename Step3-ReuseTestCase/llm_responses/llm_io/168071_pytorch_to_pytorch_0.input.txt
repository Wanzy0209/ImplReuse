Issue ID: 168071
Title: torch.nn.functional.padcrashes when padding(0, 0)to0-shape
Bug Description:
### 🐛 Describe the bug

When `0` is involved in shape of a tensor, and the 0-shape dimension is padded with `(0, 0)` in `torch.nn.functional.pad`, a `RuntimeError` arises telling that this results into a "negative" output size, in which the actual output size is definitely not negative but zero. 

A minimal example: 
```python
import torch as pt
x0 = pt.zeros((6, 0))
x1 = pt.nn.functional.pad(
    x0, (0, 0, 0, 24)
)
print(x1.shape)
```

Expected output: 
```
torch.Size([30, 0])
```

Actual error: 
```
---------------------------------------------------------------------------
RuntimeError                              Traceback (most recent call last)
Cell In[13], line 3
      1 import torch as pt
      2 x0 = pt.zeros((6, 0))
----> 3 x1 = pt.nn.functional.pad(
      4     x0, (0, 0, 0, 24)
      5 )
      6 print(x1.shape)

RuntimeError: The input size 0, plus negative padding 0 and 0 resulted in a negative output size, which is invalid. Check dimension 1 of your input.
```

HINT: This issue is completely different with #152750. #152750 padded the `0`-shape dimension, but not with `(0, 0)`. 

Btw, is it not encouraged to use 0-shape tensors in PyTorch in current version? There seems to be plenty of bugs.
