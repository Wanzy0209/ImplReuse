Issue ID: 160575
Title: Windows 2.8.0+cu126 doesn't have Maxwell kernel support?
Bug Description:
### 🐛 Describe the bug

When running 2.8.0, if you run a cu128/cu129 build on a Maxwell box, Torch will complain due to not having kernels due to the decision to deprecate support for Maxwell/Pascal and direct you to install 12.6 instead.

However, it seems (at least on Windows) that the builds don't actually have a CUDA kernel for sm_52.
