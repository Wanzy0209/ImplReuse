Issue ID: 164286
Title: GradTrackingTensor does not copy layout (issue with torch.sparse)
Bug Description:
### 🐛 Describe the bug

`GradTrackingTensor` wrapped around a sparse tensor breaks with `torch.sparse.mm` due to a failing layout check. Specifically, here is a minimal example:

```
import torch


def f(a, x):
    print(a.layout, x.layout)

    return torch.sparse.mm(a, x)


a = torch.sparse_coo_tensor(torch.tensor([[0, 1, 2], [1, 2, 0]]), [1.0, 1.0, 1.0])
x = torch.tensor([1.0, 3.0, 2.0])[:, None]
print(f(a, x))  # works fine

vjp = torch.func.vjp(f, a, x)[1]  # fails
```

This produces the following output (note that the `print(a.layout, x.layout)` call produces different outputs depending on whether it is called inside or outside of the vjp):
