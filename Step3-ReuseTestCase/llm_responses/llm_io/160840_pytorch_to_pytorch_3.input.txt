Issue ID: 160840
Title: torch.nn.functional.interpolate generates inconsistent computation results after torch.compile
Bug Description:
### 🐛 Describe the bug

The target function, calling `torch.nn.functional.interpolate`, generates inconsistent computation results after `torch.compile`.
```python
import torch
import numpy as np

torch.manual_seed(0)
torch._inductor.config.fallback_random=True

def foo(input):
    interpolate = torch.nn.functional.interpolate(
        input,
        size=[40, 40],
        scale_factor=None,
        mode="bicubic",
        align_corners=None,
        recompute_scale_factor=None,
        antialias=False,
    )
    squeeze = interpolate.squeeze(0)
    argmin = squeeze.argmin(1)
    return argmin


np.random.seed(0)
x = np.random.uniform(0, 10, size=(1, 40, 1, 1))  # dtype = float64

cfoo = torch.compile(foo)
eager_res = foo(torch.from_numpy(x))
compile_res = cfoo(torch.from_numpy(x))
torch.testing.assert_close(eager_res, compile_res)
```
