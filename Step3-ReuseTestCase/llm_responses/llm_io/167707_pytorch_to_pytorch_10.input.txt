Issue ID: 167707
Title: torch.profiler.profile cannot save trace
Bug Description:
Repro:
```python
import torch

worker_name = "trace"
profile = torch.profiler.profile(
        activities=[
            torch.profiler.ProfilerActivity.CPU,
            torch.profiler.ProfilerActivity.CUDA,
        ],
        on_trace_ready=torch.profiler.tensorboard_trace_handler(
            ".", worker_name=worker_name, use_gzip=True
        ),
    )


profile.start()

x = torch.randn(2, device="cuda")
y = x + 21
z = x * 15
profile.stop()
```

On Pytorch main branch (d105e3a198ec40865692fc1f72b9e95b324f97ab, Nov 12), the saved trace is broken.
On PyTorch 2.8.0, the saved trace can be viewed correctly.
On PyTorch 2.9.1, the saved trace can be viewed correctly.

This breaks [vllm profiler](https://github.com/vllm-project/vllm/blob/main/vllm/v1/worker/gpu_worker.py#L108-L120).
