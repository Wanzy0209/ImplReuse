Title: [dynamo] Add most recent bytecode/Python stack context to graph break developer error context
Bug Description:
Log the last k (k = 50?) bytecode instructions traced, along with the state of the symbolic Python stack.

i.e. print the last k outputs of `TORCH_LOGS=trace_bytecode` when logging a graph break.

For example,
```python
import torch


@torch.compile(backend="eager")
def fn(x):
    y = x + 1
    z = x + y
    torch._dynamo.graph_break()
    return z


fn(torch.ones(3))
```
