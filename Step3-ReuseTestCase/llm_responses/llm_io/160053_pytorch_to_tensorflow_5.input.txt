Issue ID: 160053
Title: torch.Pad(mode="circular")doesn't work for 4D or 5D input despite error msg
Bug Description:
### 🐛 Describe the bug

```python
import torch
import torch.nn.functional as F
a = torch.empty(2,2,2,2)
F.pad(a, (1,1), mode="circular")
```

Error:
`NotImplementedError: Only 2D, 3D, 4D, 5D padding with non-constant padding are supported for now`

I have searched thru previous issues, and while there are some similar bugs which may possibly (but not sure) stem from the same underlying issue, but none that seems to directly note this bug.

The problem is mostly that there is a difference between the error message and the result. Either the error message should state correctly what shapes are accepted, or padding should work for this size.
