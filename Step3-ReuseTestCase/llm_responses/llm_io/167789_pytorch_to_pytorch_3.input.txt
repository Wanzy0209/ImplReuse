Issue ID: 167789
Title: [dynamo] sys.setrecursionlimit doesn't seem to do anything
Bug Description:
```python
import sys
import torch

def fn(x, n):
    if n == 0:
        return x
    return fn(x, n - 1) + 1

@torch.compile(backend="eager")
def outer(x):
    return fn(x, 1000)

sys.setrecursionlimit(10000000)
outer(torch.ones(3))
```

This code gives RecursionError even though the recursionlimit was set to a very high value. If we don't compile, then we don't hit a recursion limit. 

If we set `tstate->c_recursion_remaining` to a high value as well somewhere in C dynamo, then we run successfully. So we should add some kind of eval_frame API to modify the C recursion limit.
