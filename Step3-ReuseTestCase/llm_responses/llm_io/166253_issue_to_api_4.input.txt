Issue ID: 166253
Title: torch.full give wrong result with torch.compile and dtype=torch.float64
Bug Description:
### 🐛 Describe the bug

The value argument of `torch.full` seems to be fixed as the value in the first call after `torch.compile` if it's float64 and runned on CPU.
```
import torch


def func_nojit(x):
    return torch.full((2, ), x, dtype=torch.float64)


func_jit = torch.compile(func_nojit)

for func in [func_nojit, func_jit]:
    x1 = torch.tensor(5.0, dtype=torch.float64)
    x2 = torch.tensor(10.0, dtype=torch.float64)
    print(func(x1))
    print(func(x2))
```

I get:
```
tensor([5., 5.], dtype=torch.float64)
tensor([10., 10.], dtype=torch.float64)
tensor([5., 5.], dtype=torch.float64)
tensor([5., 5.], dtype=torch.float64)
```
