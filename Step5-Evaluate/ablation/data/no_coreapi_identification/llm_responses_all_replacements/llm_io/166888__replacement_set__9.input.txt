Issue ID: 166888
Title: [Inductor] nameError when using .item() on float tensor arg in torch.compile
Bug Description:
### 🐛 Describe the bug

When compiling a fn with `torch.compile` that calls `.item()` on a float tensor arg (e.g., for use in `torch.clamp`), the generated triton kernel fails with `NameError: 'zuf0' is not defined`.

```python
import torch
def f(x, max_val):
    y = torch.clamp(x, 0, max_val.item())
    return y

compiled_func = torch.compile(f, backend='inductor', fullgraph=True)
x = torch.randn(10, 20, 30, device='cuda')
max_val = torch.tensor(5.0, device='cuda')
compiled_func(x, max_val)
```
