Issue ID: 166841
Title: aoti_compile_and_package incorrectly generates CUDA kernel call for CPU scatter_add_ in multi-device models
Bug Description:
### 🐛 Describe the bug

When using `torch._inductor.aoti_compile_and_package` on a model that contains both CPU and CUDA operations, the compiler incorrectly generates a call to the CUDA-specific kernel (`aoti_torch_cuda_scatter_reduce_two_out`) for a `scatter_add_` operation that is running entirely on CPU tensors.
This bug is only triggered when the exported graph contains both CPU and CUDA device types. If the model is CPU-only, the correct CPU kernel is generated.
This leads to a runtime exception when the compiled model is loaded and run, as the CUDA-specific kernel is (correctly) called with CPU tensors, causing a `CUDAGuardImpl initialized with non-CUDA DeviceType: cpu` error.

        # 2. Move result to CUDA and continue on CUDA
        v = vector + scatter_result.to(vector.dtype).to('cuda')
