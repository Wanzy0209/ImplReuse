Issue ID: 161562
Title: set_fullgraph(False)actually skips the frame if a graph break happens
Bug Description:
### 🐛 Describe the bug

I think I might be getting this wrong, but reporting just in case.

The code below is a simple reproducer that would produce a graph break in the absence of `set_fullgraph(False)`. I expect set_fullgraph to split the graph into two parts (`y := x + 10` and `f.x - y`), but once a graph break occurs, the frame is skipped and the code runs on eager.

```python
import torch

@torch.compile(backend="eager", fullgraph=True)
def fn(x):
    y = x + 10

    with torch._dynamo.set_fullgraph(False):
        class Foo:
            def __init__(self, x):
                self.x = x

    f = Foo(x)
    return f.x - y

x = torch.tensor([1.0])
y = fn(x)
print(y)
```

It looks like it is missing a `@break_graph_if_unsupported` in the `LOAD_BUILD_CLASS` opcode?
