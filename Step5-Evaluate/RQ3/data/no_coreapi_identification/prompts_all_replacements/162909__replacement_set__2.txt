Issue ID: 162909
Title: RuntimeError: Intel XPU device doesn't support querying free memory on PyTorch 2.9+xpu (LN/L Arc 140V)
Bug Description:
### 🐛 Describe the bug

Description:
I am experiencing an issue when trying to load models on an Intel GPU (LN/L Arc 140V) using PyTorch 2.9.0+xpu. Any attempt to load a model causes a RuntimeError related to torch.xpu.mem_get_info(). This prevents me from running even small models that should fit into GPU memory.

Steps to reproduce:
```python
from transformers import AutoModelForCausalLM, AutoTokenizer
import torch

print("Using device:", "xpu" if torch.xpu.is_available() else "cpu")

model_name = "./Qwen3-06B"  # path to local model

model = AutoModelForCausalLM.from_pretrained(
    model_name,
    device_map="auto",  # tried also device_map="sequential"
    torch_dtype=torch.float16
)
tokenizer = AutoTokenizer.from_pretrained(model_name)
```

Error message:

RuntimeError: The device (Intel(R) Graphics [0x64a0]) doesn't support querying the available free memory.
