Bug Description:
### 🐛 Describe the bug

I am using the tensorly library (https://tensorly.org) to compute a PARAFAC decomposition of a tensor:

```python

tl.set_backend("pytorch")
from tensorly.decomposition import parafac

x = torch.ones(12,3,12).to("mps")
print(x.shape)

weights, factors = parafac(x.detach(), 12, init="random", tol=1e-6)

a, m, b = factors
```
