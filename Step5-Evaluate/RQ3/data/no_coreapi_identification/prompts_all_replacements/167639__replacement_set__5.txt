Title: torch.compile incompatible with CUDA Graph capture due to RNG state access during compilation
Bug Description:
### 🐛 Describe the bug

Description:
When using torch.compile() inside a CUDA Graph capture context, the compilation process fails because it attempts to access CUDA RNG state, which is prohibited during graph capture. This prevents users from combining two important PyTorch performance optimization features.
