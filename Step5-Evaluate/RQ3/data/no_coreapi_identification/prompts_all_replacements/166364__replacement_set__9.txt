Issue ID: 166364
Title: Flex Attention does not support learnable scalar
Bug Description:
### 🐛 Describe the bug

Flex Attention does not support learnable scaler.

1. Without compiling: Cause error: `vmap(<lambda>(), ...): () can not return a BatchedTensor when out_dim is None` in backward. Forward works well.
2. With compiling: Forward fails too. 

reproduce code: 
```
temp = nn.Parameter(torch.tensor(0.0))
    def score_mod(score, b, h, q, kv):
        #print(f"const: {const}")
        score = score + temp
        return score
```


After several tries, I found following code can work: 
```
temp = nn.Parameter(torch.randn(B, ))) # where be is Batch size. 
    def score_mod(score, b, h, q, kv):
        #print(f"const: {const}")
        score = score + temp[b]
        return score
```
