Issue ID: 161361
Title: Metal Performance Shaders (MPS) Bug on very simple linear regression
Bug Description:
### 🐛 Describe the bug

When running this simple linear regression toy example on the MPS backend (Apple Silicon GPU), the model does not learn — the weights are not updated and the loss remains constant across epochs.
However, if I change the device to "cpu", the exact same code works as expected: the weights are updated and the loss decreases over time.
This suggests that manual parameter updates using .data do not behave correctly on MPS, even though they work fine on CPU, I have not tested with CUDA yet.
