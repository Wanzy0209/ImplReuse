Issue ID: 161415
Title: torch.rand_like does not respect input stride
Bug Description:
### 🐛 Describe the bug

The function torch.rand_like does not respect the input stride. The code below fails on `nvcr.io/nvidia/pytorch:25.08-py3`:

```
import torch

input_tensor  = torch.empty_strided(size = [1792, 1899, 160], stride = (303872, 160, 1))
output_tensor = torch.rand_like(input_tensor)
assert input_tensor.stride() == output_tensor.stride()
```

I believe the PR: https://github.com/pytorch/pytorch/pull/159614 tried to fix it, but never got merged.
