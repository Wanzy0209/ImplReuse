Issue ID: 162302
Title: torch.linalg.tensorinv produces incorrect results on CUDA (values doubled compared to CPU)
Bug Description:
### 🐛 Describe the bug

When computing the inverse of a 4×4 matrix using torch.linalg.tensorinv with ind=1, the CPU and CUDA results differ significantly. On CUDA, the output values are exactly 2× larger in magnitude than the CPU result, which indicates a device-specific bug in the CUDA implementation. This issue is reproducible with dtype=torch.float32 and affects result correctness.

```
import torch

A = torch.tensor([
    [4.0, -3.0,  2.0, -1.0],
    [-1.0,  2.0, -3.0,  4.0],
    [3.0, -4.0,  1.0, -2.0],
    [-2.0,  1.0, -4.0,  3.0]
], dtype=torch.float32)

cpu_result = torch.linalg.tensorinv(A, ind=1)
gpu_result = torch.linalg.tensorinv(A.to("cuda"), ind=1)

print("CPU:\n", cpu_result)
print("GPU:\n", gpu_result)
print("CPU / GPU elementwise ratio:\n", cpu_result / gpu_result.cpu())
```
