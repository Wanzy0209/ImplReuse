Bug Description:
### 🐛 Describe the bug

repro steps:
1) save the model in AOTI package in Linux.
python model.py
2) load the saved AOTI package in the same Linux machine.
python inference.py

The example model is intentionally to test graph break situation, so the relu kernel is the torch executed op, other ops are torch_tensorrt executed op.
The model can be loaded successfully from pt2 file, however when I try to inference, it throw segfault exception during the execution of torch relu kernel(torch-tensorrt kernel has been executed successfully).

Currently, it is only failing on graph break, if the graph is completely build with torch or completed build build torch_tensorrt, aoti save and load is working.
