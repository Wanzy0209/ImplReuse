Issue ID: 165838
Title: Inconsistent output with same input using equivalent block masks created via different methods in Flex Attention
Bug Description:
### 🐛 Describe the bug

I observed that Flex Attention produces different outputs when using logically identical block masks created through different implementations.

For example, the following two functions both create equivalent causal masks in logic:
```python
def block_mask_fn_1(batch: Tensor, h: Tensor, q: Tensor, kv: Tensor):
    causal_mask = (q >= kv)
    return causal_mask

def block_mask_fn_2(batch: Tensor, h: Tensor, q: Tensor, kv: Tensor):
    causal_mask = hand_made_causal_mask[q, kv]
    return causal_mask
```
However, the outputs can differ even when the inputs are fixed.
This discrepancy does not always occur — it happens around 6 times out of 500 when `seq_len = 16`, but becomes much worse at longer sequence lengths (370 out of 500 when `seq_len = 2048`).


**Environment**
PyTorch:  2.10.0.dev20250914+cu128
GPU: L20 x1
