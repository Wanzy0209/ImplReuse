Issue ID: 160197
Title: LBFGS always raises warning about converting a tensor with requires_grad=True to a scalar?
Bug Description:
### 🐛 Describe the bug

With torch version 2.8.0, converting a tensor with `requires_grad=True` to a scalar now raises a `UserWarning`. I think this warning is now always raised when using a [closure](https://docs.pytorch.org/docs/stable/optim.html#optimizer-step-closure) function with LBFGS, because LBFGS calls `float(closure())`. Is this expected behavior? How should I avoid this warning?

Here's a simple minimal example, which just tries to minimize the MSE between two small random tensors:

```python
import warnings
warnings.simplefilter('error')
import torch
print(torch.__version__)
a, b = torch.rand((2, 32, 32))
a.requires_grad_()
optimizer = torch.optim.LBFGS([a])
loss_fn = lambda x, y: (x-y).pow(2).mean()

def closure():
    optimizer.zero_grad()
    loss = loss_fn(a, b)
    loss.backward()
    return loss

for i in range(100):
    optimizer.step(closure)
    print(i, loss_fn(a, b))
```

As above, the warning gets raised, and changing the optimizer to Adam leads to behavior as normal.
