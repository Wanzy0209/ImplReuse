Issue ID: 160495
Title: [inductor]self.dim() cannot be 0 to view ComplexFloat as Float (different element sizes)in inductor but eager can pass the check
Bug Description:
### 🐛 Describe the bug

When two complex tensors are element-wise-added, if one of them is an empty tensor, execution will crash with `RuntimeError: self.dim() cannot be 0 to view ComplexFloat as Float (different element sizes)`.  However, eager can succeed in this case.
```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from torch._inductor import config

config.fallback_random = True
torch.set_grad_enabled(False)
torch._dynamo.config.capture_dynamic_output_shape_ops = True

def eager_fn(x, y):
    return x + y

@torch.compile()
def fn(x, y):
    return x + y

x = torch.randn(1, dtype=torch.complex64)
y = torch.empty((), dtype=torch.complex64)

eager_fn(x, y)
print("eager success")
fn(x, y)
print("compiler success")
```
