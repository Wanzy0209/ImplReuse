Title: Simple float64 Matmul on RX 7600xt with ROCm 6.4.3 and PyTorch 2.8 Crashes with Segfault
Bug Description:
### 🐛 Describe the bug

The following code crashes with a segmentation fault with pytorch version 2.8.0+rocm6.4 with userland ROCm 6.4.3 libraries installed; version 2.7.1+rocm6.3 with userland ROCm 6.3.4 libraries installed works fine per testing:
```python
import torch
torch.set_default_dtype(torch.float64)
x = torch.randn(1000, 1000, device="cuda")
y = torch.randn(1000, 1000, device="cuda")
z = x @ y
print(z[0, 0])
```
