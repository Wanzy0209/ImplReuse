Title: error C2039: 'load': is not a member of 'torch::jit'
Issue ID: 162156
Original bug description: ### 🐛 Describe the bug

Hello, I have exported my model using torch.jit.trace() in Python. Here is the code
```
device = torch.device("cuda")
example_input = torch.randn((64, 3, 64, 64)).to(device)

# Trace the model
traced_model = torch.jit.trace(model, example_input)
traced_model = torch.jit.optimize_for_inference(traced_model)
traced_model.save(os.path.join(repo_dir, "opt_traced_model.pt"))
```
When I try to load the model in libtorch c++ with the following example code
```
#include <torch/torch.h>
#include <iostream>

int main() {
    // Load the TorchScript model
    torch::jit::script::Module module;

    try {
        module = torch::jit::load("D:\\20250821-merged\\traced_model.pt");
    }
    catch (const c10::Error& e) {
        std::cerr << "Error loading the model\n";
        return -1;
    }

    // Create an input tensor
    torch::Tensor input = torch::randn({1, 10});

    // Forward pass
    std::vector<torch::jit::IValue> inputs;
    inputs.push_back(input);
    torch::Tensor output = module.forward(inputs).toTensor();

    std::cout << "Output: " << output << std::endl;

    return 0;
}
```
I get the error
`error C2039: 'load': is not a member of 'torch::jit'`

in the Python implementation `jit.load()` of course exists, while I cannot find it in the C++ API. Am I missing some include files?

My configuration is

- Pytorch 2.8.0+ cu128
- Libtorch 2.8.0+ cu128 the Debug library
- Windows 10 using Visual Studio 2022
- SDK version 10.0.22621.0 to target Windows 10.0.19045
- MSVC 19.43.34808.0
