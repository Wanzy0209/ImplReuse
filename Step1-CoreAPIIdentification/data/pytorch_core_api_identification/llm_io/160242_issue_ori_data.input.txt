Title: torch.compileproduces output mismatch vs eager float64 for some seeds
Issue ID: 160242
Original bug description: ### 🐛 Describe the bug

## Issue Description
When running a model compiled with `torch.compile` in `float32` and comparing against eager execution in `float64`, outputs can differ beyond specified tolerances for certain random seeds.
For example, with global seed set to `4`, the mismatch is reproducible.
With seed `42`, the outputs match; with other seeds, mismatches also occur but not always deterministically without fixing the seed.

This suggests potential non-deterministic behavior or precision-sensitive code paths in the compiler output.
