Bug Report:
Title: torch.jit.script crashes on Python 3.14 in PyTorch 2.9.1 (__annotations__missing)
Issue ID: 167910
Original bug description: ### 🐛 Describe the bug

Calling `torch.jit.script` on a trivial `nn.Module` crashes immediately on `Python 3.14` with:

```
AttributeError: 'JITCrash' object has no attribute '__annotations__'. Did you mean: '__annotate_func__'?
```

This looks like a regression issue, and it prevents TorchScript from working at all on Python 3.14

The underlying cause is that TorchScript ( in torch 2.9 ) assumes that every nn.Module instance has a __annotations__ attribute, which is not guaranteed on Python ≥ 3.14.


### Minimal Reproducible Example:

```
import torch
import torch.nn as nn

class JITCrash(nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, x):
        return x + 1

model = JITCrash()
scripted = torch.jit.script(model)
```
