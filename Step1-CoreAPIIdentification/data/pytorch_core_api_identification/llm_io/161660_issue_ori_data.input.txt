Bug Report:
Title: Add a torch_stable target for CppExtensions that rely on the stable ABI
Issue ID: 161660
Original bug description: ### 🚀 The feature, motivation and pitch

We want to make sure that extensions relying on the stable ABI do not accidentally include and use any headers within libtorch that are non-stable.

As a stopgap in https://github.com/pytorch/pytorch/pull/161658/ TensorBase.h checks for a `TORCH_STABLE_ONLY` flag and will error during compilation if it's defined. Extensions relying on the stable ABI can pass this in to the `extra_compile_args` argument of `CppExtension`

In the longer term, we want a `torch_stable` target that will exclude all these headers which is integrated with CppExtension
