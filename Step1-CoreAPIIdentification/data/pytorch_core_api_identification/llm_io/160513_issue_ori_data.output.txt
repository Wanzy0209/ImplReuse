    *   **Reproducible Example:**

        *   Inside the function `test`, it does `0.5 * x[0]` where `x[0]` is a 0-d tensor.

        *   It fails at `torch.tensordot` due to dtype mismatch.
    *   **Diagnostic Example:**
        *   Uses `torch.autograd.forward_ad.make_dual` to create dual tensors.
        *   Shows that `1.0 * dual0d` (where `dual0d` is a 0-d dual tensor) causes the tangent to become `float64`.
    *   **Workarounds:** Use a tensor scalar or apply scalar before slicing.
