Bug Report:
Title: torch compile does not handle out_dtype argument in torch.mm (but succeeds with torch.bmm)
Issue ID: 163275
Original bug description: ### 🐛 Describe the bug

```
import torch

A = torch.rand((1024, 1024), device="cuda", dtype=torch.float16)
B = torch.rand((1024, 1024), device="cuda", dtype=torch.float16)

@torch.compile
def linear(weight, input):
    return torch.mm(input, weight, out_dtype=torch.float32)

linear(A, B)
```
