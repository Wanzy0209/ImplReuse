Looks like its complaining about these https://github.com/python/cpython/blob/v3.14.0rc1/Include/internal/pycore_stackref.h#L274C1-L274C71

Related issues: 
https://github.com/cython/cython/issues/6783
and
https://github.com/python/cpython/issues/130931

This is happening with 3.14 rc1

Options to mitigate this:
1) Try compiling with ./std:c++20 or whatever it suggests
2) Try to get this fixed upstream and wait until it's fixed
3) Don't include pycore_xxx headers in C++. They're intended to be internal only and CPython is a C, not C++ project so this kinda thing is going to break frequently. The thing PyTorch has done in other places is to make a small C file that includes whatever headers we care about like pycore_code.h and re-expose the important functionality as functions to be used in C++


For enabling 3.14 builds will fallback on option 3.14 however we need to fix it in dynamo.
