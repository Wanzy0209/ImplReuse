Bug Report:
Title: DTensor withtorch.compilefails onF.conv2d- Sharding propagation error with FakeTensors
Issue ID: 167091
Original bug description: ### 🐛 Describe the bug

`torch.nn.functional.conv2d` fails when DTensor inputs are used with `torch.compile`, raising a Dynamo runtime error during fake tensor execution:
```
torch._dynamo.exc.TorchRuntimeError: Dynamo failed to run FX node with fake tensors: call_function <built-in method conv2d ...>
got RuntimeError('Sharding propagation failed on op Op(op=aten.convolution.default, ...')
```
```python
import torch
from torch.distributed.tensor import DTensor, Replicate, distribute_tensor, init_device_mesh
import torch.nn.functional as F

# construct a device mesh with available devices (multi-host or single host)
device_mesh = init_device_mesh("cuda", (2, 1))
placement = [Replicate(), Replicate()]

def fn(inputs, kernel, bias):
    return F.conv2d(input=inputs, weight=kernel, bias=bias, padding=1)

jitted_fn = torch.compile(fn)

# With square kernels and equal stride
inputs = torch.randn(1, 4, 5, 5)
kernel = torch.randn(8, 4, 3, 3)
bias = torch.randn(8)

d_inputs = distribute_tensor(inputs, device_mesh=device_mesh, placements=placement)
d_kernel = distribute_tensor(kernel, device_mesh=device_mesh, placements=placement)
d_bias = distribute_tensor(bias, device_mesh=device_mesh, placements=placement)

result = fn(d_inputs, d_kernel, d_bias)  # works
jitted_result = jitted_fn(d_inputs, d_kernel, d_bias)  # fails
```

```bash
python3 -m torch.distributed.run --nproc_per_node=2 <example_file.py>
```
