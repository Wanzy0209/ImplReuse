Bug Report:
Title: [compile][cudagraphs] Fail or loud warning with excessive rerecording
Issue ID: 162299
Original bug description: ### 🐛 Describe the bug

In some cases (like re-recording on symint), cudagraph can end up with excessive re-recording. For an end user, this is completely silent, and at the end they see very bad speedups. 

It gives an impression that torch.compile as a whole was bad. But if they just disabled cudagraph, they would still be able to reap large benefits. 

I saw this in transfomers repo where they had reduce-overhead by default. More background is that  `transformers` users control compile by just using a flag, and they have no idea that cudagraphs is turned ON, the compile call is hidden from the user. This can be a common pattern in many other tools as well. More details at https://docs.google.com/document/d/1HzcKdxjuz4SniEq-5h56FyRAAKPlx_YXiZClE4US2q4/edit?tab=t.0#bookmark=id.r48wy68nhevn

Therefore, we must raise loud warning or consider even failing hard.
