1.  **Analyze the Bug Report:**
    *   **Title:** scripted models wrongly cast integers to floats
    *   **Description:** When using `torch.jit.script`, the operation `a ** b` (where `a` and `b` are integers) outputs a float instead of an integer.
    *   **Code Example:**
        ```python
        import torch

        class MyModule(torch.nn.Module):
            def forward(self, x: torch.Tensor) -> torch.Tensor:
                print(3**2)
                return x

        model = MyModule()
        model_script = torch.jit.script(model) # The key line
        x = torch.rand((10,))
        model(x) # Prints 9 (int)
        model_script(x) # Prints 9. (float)
        ```
    *   **Trigger Conditions:** Using `torch.jit.script`.
    *   **Environment:** PyTorch 2.7.1+cu118.
