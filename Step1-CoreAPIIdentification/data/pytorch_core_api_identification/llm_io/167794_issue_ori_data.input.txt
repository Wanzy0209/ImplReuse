Bug Report:
Title: [Metal Backend] Metal create column major tensor
Issue ID: 167794
Original bug description: ### 🐛 Describe the bug

## Metal backend tensor layout is column major by default

```
weights = torch.randint(0, 2, (K, N), device="mps").float() * 2 - 1

weights_fp16 = weights.half()

print(f"weights_fp16 strides : {weights_fp16.stride(0), weights_fp16.stride(1)}, shape={weights_fp16.shape}")
assert(weights_fp16.is_contiguous())
```

When debugging we found this outputs:

```
weights_fp16 strides : (1, 1), shape=torch.Size([16, 1])
```

which means by default metal backend creates column major backend by default.

ref: https://github.com/ml-explore/mlx-lm/pull/609
