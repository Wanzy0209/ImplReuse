Bug Report:
Title: Build failed due to 'struct c10::cuda::DriverAPI' has no member named 'cuCtxGetCurrent_'
Issue ID: 166799
Original bug description: While compiling CUDAGreenContext.cpp with CUDA version 12.3, because of the access to undefined member functions.

```bash
  /home/irshadcc/Documents/Projects/pytorch/aten/src/ATen/cuda/CUDAGreenContext.cpp:23:54: error: ‘struct c10::cuda::DriverAPI’ has no member named ‘cuCtxGetCurrent_’
     23 |   C10_CUDA_DRIVER_CHECK(c10::cuda::DriverAPI::get()->cuCtxGetCurrent_(&pctx));
```

The compilation failed because some functions are not defined for CUDA version less than 12.3
https://github.com/pytorch/pytorch/blob/main/c10/cuda/driver_api.h#L52

In order to fix this build issue, we should set macro HAS_CUDA_GREEN_CONTEXT to 0 when cuda version is less than 12.3
