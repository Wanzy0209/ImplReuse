Bug Report:
Title: bmm and baddbmm perf regression on CPU
Issue ID: 162553
Original bug description: As called out by @jainapurva, https://github.com/pytorch/pytorch/actions/workflows/operator_benchmark.yml reports a significant regression on the following 2 ops on CPU:
* `bmm_B128_M64_N32_K64_cpu_dtypetorch.bfloat16`
* `baddbmm_B128_M64_N32_K64_cpu_dtypetorch.bfloat16`

This workflow was added by Intel for CPU a while ago, and there is interest from the team to expand this to cover `torch.compile` and CUDA too, i.e. https://github.com/pytorch/pytorch/pull/161394.

We should look into these regressions, and decide if they need to be fixed.  And if yes, before or after 2.9 release.  In the longer term, if op_benchmark workflow is proven useful, we need to find a proper owner to monitor it
