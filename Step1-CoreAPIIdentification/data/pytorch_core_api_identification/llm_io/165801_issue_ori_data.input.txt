@drisspg noticed that cuDNN wasn't being selected as the default backend for SDPA where expected.

https://github.com/pytorch/pytorch/blob/e50dc40d28ba409930023c77a031ec0dd20fd73b/.ci/docker/common/install_cuda.sh#L132

https://github.com/pytorch/pytorch/blob/9315f44cd64d6e25abc30e8db35fb0e4d6141eb6/.github/scripts/generate_binary_build_matrix.py#L67
