Bug Report:
Title: DataLoader workers freeze when num_workers > 0**
Issue ID: 167909
Original bug description: ### 🐛 Describe the bug

When using DataLoader with num_workers > 0, the training loop freezes randomly.
The issue disappears when num_workers = 0.

### Versions

from torch.utils.data import DataLoader, Dataset
import time
class MyDataset(Dataset):
    def __getitem__(self, i):
        time.sleep(0.1)
        return i
    def __len__(self):
        return 50

loader = DataLoader(MyDataset(), batch_size=8, num_workers=4)
for batch in loader:
    print(batch)
