Bug Report:
Title: Unknown CUDA arch 10.1 when building C++ extension against 2.9.0+cu128
Issue ID: 166120
Original bug description: ### 🐛 Describe the bug

Explicitly specifying `10.1` in `TORCH_CUDA_ARCH_LIST` makes extension build on torch 2.9.0 and CUDA < 13.0 (tested on 12.8 and 12.9) fail with `ValueError: Unknown CUDA arch (10.1) or GPU not supported` from `utils/cpp_extension.py:_get_cuda_arch_flags`. This is presumably related to the renaming of `sm_101` to `sm_110` in CUDA 13.0 (#156176, 9c5601ecc316e5be548038bc24411acd7c74a032).

```dockerfile
FROM pytorch/pytorch:2.9.0-cuda12.8-cudnn9-devel
RUN apt-get update && apt-get install -y curl
RUN curl -sSL https://github.com/pytorch/extension-cpp/archive/0ec4969.tar.gz | tar -xvz && \
        sed -i 's/torch.cuda.is_available()/True/g' extension-cpp-0ec4969c7bc8e15a8456e5eb9d9ca0a7ec15bc95/setup.py
WORKDIR extension-cpp-0ec4969c7bc8e15a8456e5eb9d9ca0a7ec15bc95
ENV TORCH_CUDA_ARCH_LIST=10.1
RUN pip install --break-system-packages --no-build-isolation -e .
```
