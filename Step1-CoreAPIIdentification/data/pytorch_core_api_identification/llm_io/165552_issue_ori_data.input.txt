Bug Report:
Title: Feature Request: Add a mechanism to track "dead" ReLU activations
Issue ID: 165552
Original bug description: ### 🚀 The feature, motivation and pitch

A common issue with the ReLU activation function is that it can lead to “dead neurons” — units that consistently output zero and therefore stop contributing to learning. This can make debugging or diagnosing model performance more difficult.

It would be helpful if PyTorch could provide an optional mechanism to track and report how many activations in a given layer are “dead” during training or evaluation. For example, the mechanism could track all neuron outputs across training iterations, and if a neuron outputs zero almost all the time for a long period, it would be flagged as “dead.”
