Bug Report:
Title: PyTorch nightly fails on Windows with RTX 5080 (CUDA 13.0): missing torchaudio wheels + torchvision dependency conflict
Issue ID: 167817
Original bug description: ### 🐛 Describe the bug

### System Info
- OS: Windows 11
- GPU: NVIDIA GeForce RTX 5080
- Driver: 581.80
- CUDA reported from nvidia-smi: 13.0
- Python: 3.11.8
- Environment: venv

### Summary
PyTorch nightly fails to install correctly on Windows when using RTX 5080 (CUDA 13).

The following issues occur:
1. `torchaudio` has **no available wheels** for Windows + Python 3.11 + CUDA 12.4/12.5/13.
2. `torchvision` nightly requires `torch==2.7.0.dev20250225+cu124`, but this torch version is **not available** for my environment.
3. Stable Diffusion WebUI reports:
   `RuntimeError: Torch is not able to use GPU`
4. Only CPU mode works.

### Full Error Logs (from my installation)
- ERROR: No matching distribution found for torchaudio
- ERROR: Cannot install torch and torchvision because these package versions have conflicting dependencies
- torch==2.7.0.dev+cu124 not found for Python 3.11
- GPU is not recognized even though nvidia-smi reports CUDA 13.0

### Additional Info
nvidia-smi output:
CUDA Version: 13.0  
Driver Version: 581.80  
GPU: GeForce RTX 5080

### Expected
- Provide Windows wheels for torch / torchvision / torchaudio that support CUDA 13 and new RTX 50-series GPUs.
- Provide compatible nightly builds for Python 3.11 or documented support status.

Thank you!
