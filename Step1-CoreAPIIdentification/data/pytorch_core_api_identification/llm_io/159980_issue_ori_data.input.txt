Opening this RFC to discuss CUDA version support for future PyTorch release 2.9:

Migration to CUDA 13.0 is planned for release 2.9

Hence following few options possible:

Option 1 - CUDA 12.8 (Stable) , 12.9.1 and 13.0 
CUDA 12.8 CUDNN 9.x - Stable version - Version Release to Pypi 
CUDA 12.9.1 CUDNN 9.x  - Prototype version 
CUDA 13.0 CUDNN 9.x   - Prototype version

Option 2 - CUDA 12.8 and 12.9.1 (Stable) and 13.0 - Requirement here is to be able to move all Pytorch CI to 12.9.1
CUDA 12.8 CUDNN 9.x - Legacy
CUDA 12.9.1 CUDNN 9.x  - Stable version - Version Release to Pypi 
CUDA 13.0 CUDNN 9.x   - Prototype version

Option 3 - 12.9.1 (Stable)  and 13.0 - Requirement here is to be able to move all Pytorch CI to 12.9.1
CUDA 12.9.1 CUDNN 9.x  - Stable version - Version Release to Pypi 
CUDA 13.0 CUDNN 9.x   - Prototype version

Option 4 - 12.8 (Stable)  and 13.0 
CUDA 12.8 CUDNN 9.x  - Stable version - Version Release to Pypi 
CUDA 13.0 CUDNN 9.x   - Prototype version

Option 5 - CUDA 12.6 CUDA 12.8 (Stable)  and 13.0 
CUDA 12.6 CUDNN 9.x - Legacy
CUDA 12.8 CUDNN 9.x - Stable version - Version Release to Pypi 
CUDA 13.0 CUDNN 9.x   - Prototype version

Option 6 - CUDA 12.6 CUDA 12.9 (Stable)  and 13.0 - Requirement here is to be able to move all Pytorch CI to 12.9.1
CUDA 12.6 CUDNN 9.x - Legacy
CUDA 12.9 CUDNN 9.x - Stable version - Version Release to Pypi 
CUDA 13.0 CUDNN 9.x   - Prototype version
