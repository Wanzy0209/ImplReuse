Bug Report:
Title: ONNX export fails for torchvision CNN architectures
Issue ID: 166163
Original bug description: ### 🐛 Describe the bug

Some torchvision CNNs fail to export to ONNX. Specifically, I've seen issues with EfficientNet, MobileNet, and Resnet from torchvision.models, while convenxt, vgg, and squeezenet export successfully.

Failing models:
```
torchvision.models.efficientnet_b0
torchvision.models.mobilenet_v2
torchvision.models.resnet18
```

The common thread seems to be *batchnorm layers*, as the error messages include
```
<class 'ValueError'>: Key 'b_features_0_1_running_mean' does not match the name of the value 'getitem_3'. Please use the value.name as the key.
```
or
```
<class 'ValueError'>: Key 'b_bn1_running_mean' does not match the name of the value 'getitem_3'. Please use the value.name as the key.
```

Python code to reproduce:

```
import torch
import torchvision
import pandas as pd
import traceback

models = [
    torchvision.models.convnext_tiny,
    torchvision.models.efficientnet_b0,
    torchvision.models.mobilenet_v2,
    torchvision.models.resnet18,
    torchvision.models.squeezenet1_0,
    torchvision.models.vgg11,
]
results = []
for cl in models:
    try: 
        m=cl(weights=None)
        input = torch.rand((3, 224, 224))  # Example input for ResNet
        input_batch = torch.stack([input, input])
        output_batch = m(input_batch) # successfull forward pass
        output_batch.shape # torch.Size([2, 1000])

        onnx_program = torch.onnx.export(
            m,
            (input_batch,),
            dynamic_shapes=[{0: "dim_x"}],
            report=True,
            dynamo=True,
        )

        onnx_program.save("cnn_dynamic.onnx")
        results.append({
            "Model": m.__class__.__name__,
            "Status": "Success",
            "Error Type": None,
            "Error Message": None,
            "Full Traceback": None
        })
    except Exception as e:
        
        # include full error with traceback
        results.append({
            "Model": m.__class__.__name__,
            "Status": "Failed",
            "Error Type": type(e).__name__,
            "Error Message": str(e),
            "Full Traceback": traceback.format_exc()
        })
df = pd.DataFrame(results)
df.to_csv('cnn_onnx_export_results.csv', index=False)
```
