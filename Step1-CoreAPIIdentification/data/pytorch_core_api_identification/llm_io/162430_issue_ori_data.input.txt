Bug Report:
Title: OverflowError (Python int too large to convert to C long) raised in StaticCudaLauncher
Issue ID: 162430
Original bug description: ### 🐛 Describe the bug

I am hitting an `OverflowError` exception while using `torch.compile` with `reduce-overhead` mode in my program. I do not have a minimal reproduction as I believe this issue is likely dependent on setup, hardware or drivers. However I have pinpointed the cause and the fix that resolves it.

As you can see in the callstack below, the call to [`_StaticCudaLauncher._launch_kernel`](https://github.com/pytorch/pytorch/blob/main/torch/_inductor/runtime/static_cuda_launcher.py#L244) fails because one of the arguments is too large, which after debugging turns out to be `stream`.

Taking a look at the C++ side, the problem lies with this [line](https://github.com/pytorch/pytorch/blob/main/torch/csrc/inductor/static_cuda_launcher.cpp#L372) parsing the arguments. It uses the `l` (`long int`) character to parse `stream`, however it is a 64-bit value, and on my setup I consistently get large integers for the `stream` value, making the call fail. Replacing `l` with `K` (`unsigned long long`, by patching the binary image file) resolves the issue.
