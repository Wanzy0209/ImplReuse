Original bug description: ### 🐛 Describe the bug

It seems that /pytorch/.ci/pytorch/check_binary.sh is not compatible with DESIRED_PYTHON format `cp310-cp310`.

```

```


`/opt/python/cp310-cp310/bin/../lib/python310/site-packages/torch/lib/libtorch_cpu.so': No such file`

Of course, in the CI we set DESIRED_PYTHON differently when we call this, but it's still useful to be able to test this as a developer.
