Bug Report:
Title: AArch64 Inductor Perf Test build fails installing torchao
Issue ID: 160188
Original bug description: ### 🐛 Describe the bug

We are seeing consistent failures in inductor-perf-nightly-aarch64 since build [658](https://github.com/pytorch/pytorch/actions/runs/16770088383). 

If we look at the log output we can see

For build 658 👍 
```
Installing dist/ao/torchao-0.7.0+git51c87b6e-py3-none-any.whl
+ python3 -mpip install --no-index --no-deps dist/ao/torchao-0.7.0+git51c87b6e-py3-none-any.whl
Processing ./dist/ao/torchao-0.7.0+git51c87b6e-py3-none-any.whl
Installing collected packages: torchao
  Attempting uninstall: torchao
    Found existing installation: torchao 0.12.0
    Uninstalling torchao-0.12.0:
ERROR: Could not install packages due to an OSError: [Errno 13] Permission denied: 'INSTALLER'
```

but for 657 👎 
```
Installing dist/ao/torchao-0.7.0+git51c87b6e-py3-none-any.whl
+ python3 -mpip install --no-index --no-deps dist/ao/torchao-0.7.0+git51c87b6e-py3-none-any.whl
Processing ./dist/ao/torchao-0.7.0+git51c87b6e-py3-none-any.whl
Installing collected packages: torchao
Successfully installed torchao-0.7.0+git51c87b6e
```

657 doesn't seem to have an existing installation of torchao to uninstall so i've had a look in `.ci/docker` to see what has changed. We can see that the docker image indeed does change between these builds. #159300 seems a likely candidate to have caused this issue. @huydhn
