Bug Report:
Title: torch.export fails for add.Scalar/sub.Scalar
Issue ID: 161076
Original bug description: ### 🕵️‍♂️ Detected with [FACTO](https://github.com/meta-pytorch/FACTO)

### 🐛 Describe the bug

```python
import torch
import torch.nn as nn

class AddModel(nn.Module):
    def __init__(self):
        super(AddModel, self).__init__()

    def forward(self, x):
        return torch.ops.aten.add.Scalar(x, 1, 2)

x = torch.ones([3])

model = AddModel()

# this succeeds
output = model(x)

# this fails
# TypeError: too many positional arguments
torch.export.export(model, (x,))
```

This is caused because the meta function has a different schema:
```python
import torch

x = torch.ones([3])

# this succeeds
torch.ops.aten.add.Scalar(x, 1, 2)

# this fails
# TypeError: too many positional arguments
torch.ops.aten.add.Scalar(x.to("meta"), 1, 2)
```
