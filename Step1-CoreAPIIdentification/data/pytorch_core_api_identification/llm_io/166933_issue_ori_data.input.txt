Bug Report:
Title: Exporting model with float8_e4m3fn fails in torch.onnx.export with ValueError: 24 is not a valid JitScalarType
Issue ID: 166933
Original bug description: ### 🐛 Describe the bug

When trying to export a model using torch.onnx.export that contains tensors of type float8_e4m3fn, the export fails during the _jit_pass_onnx optimization step. The issue appears to be caused by a mismatch between the internal PyTorch JitScalarType and the value used in the TorchScript IR for float8_e4m3fn.
