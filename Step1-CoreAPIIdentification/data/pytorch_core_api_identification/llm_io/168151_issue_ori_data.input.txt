Bug Report:
Title: double free or corruption (out)
Issue ID: 168151
Original bug description: ### 🐛 Describe the bug

I am getting a weird 'double free or corruption' error when I move a tensor to GPU on a Jetson Nano. I am running the example through a Docker container. 
I am not sure if this is more of an issue of Torch or Nvidia drivers. A minimal example:
```C++
#include <iostream>
#include <torch/torch.h>

int main()
{
    float ptr[1] = {0};
    torch::Tensor input = torch::from_blob(ptr, {1, 1, 1, 1}).toType(torch::kFloat32);
    input = input.to(torch::kCUDA);
    std::cout << input << std::endl;
    return 0;
}
```

by not moving the tensor to GPU it succeeds. Cloning the tensor does not solve it. The same issue happens in python. And if I use other ways to create the tensor other than `from_blob`.

Interestingly, if I enable the address sanitizer it succeeds.
```ruby
target_link_options(${PROJECT_NAME} PRIVATE -Werror -fsanitize=address -fsanitize=undefined -fno-sanitize-recover=all -fsanitize=float-divide-by-zero -fsanitize=float-cast-overflow -fno-sanitize=null -fno-sanitize=alignment)
target_link_options(${PROJECT_NAME} PRIVATE -fsanitize=address -fsanitize=undefined -fno-sanitize-recover=all -fsanitize=float-divide-by-zero -fsanitize=float-cast-overflow -fno-sanitize=null -fno-sanitize=alignment)
```
