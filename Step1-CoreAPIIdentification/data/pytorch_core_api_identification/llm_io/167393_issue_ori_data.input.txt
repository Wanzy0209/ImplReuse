Bug Report:
Title: [dynamo, nested graph breaks] Graph breaks improperly suppressed as duplicate graph break
Issue ID: 167393
Original bug description: Nested graph breaks that happen at the same line but with a different stack trace have their user stack suppressed when they should not.

```python
import torch

torch._dynamo.config.nested_graph_breaks = True


def inner(x):
    x = x + 1
    torch._dynamo.graph_break()
    return x + 2


@torch.compile(backend="eager")
def outer(x):
    x = inner(x + 4) + 8
    return inner(x) + 16


outer(torch.ones(3))
```
