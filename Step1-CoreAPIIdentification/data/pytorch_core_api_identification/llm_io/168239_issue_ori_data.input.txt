Bug Report:
Title: [torch.compile] Inductor cache ignore load from disk flag without disabling the cache
Issue ID: 168239
Original bug description: ### 🚀 The feature, motivation and pitch

For the test purposes, we need to ignore the inductor cache to be loaded from disk but we don't want the cache to be disabled completely.

In more details, we want to have the first compilation in a test not hitting the cache but subsequent compilation must hit it. However, with inductor config `force_disable_caches=False` in case of multiple test runs we hit the cache on the first compilation.  With inductor config `force_disable_caches=True` we can't test the cache hits for subsequent compilations.

So it would be helpful to have the option either to trigger the cache cleaning or to avoid loading the cache from disk.

### Alternatives

Currently, we have to explicitly make the test idempotent, taking into account that caches could already be loaded and the first compilation doesn't take a place.
