Bug Report:
Title: Pytorch wheel index does not contain hashes for recent versions
Issue ID: 164347
Original bug description: ### 🐛 Describe the bug

See eg `https://download.pytorch.org/whl/cu126/torch`. This contains URLs
```
https://download.pytorch.org/whl/cu126/torch-2.6.0%2Bcu126-cp312-cp312-manylinux_2_28_x86_64.whl#sha256=6bc5b9126daa3ac1e4d920b731da9f9503ff1f56204796de124e080f5cc3570e
https://download.pytorch.org/whl/cu126/torch-2.8.0%2Bcu126-cp312-cp312-manylinux_2_28_x86_64.whl
```
For versions >2.6, these do not contain hashes. This create problems downstream. For example, the `pylock.toml` files produced by `uv` containing these packages don't include a hash, which violates the `pylock.toml` [spec](https://packaging.python.org/en/latest/specifications/pylock-toml/#packages-wheels-hashes).

### Versions

later than 2.6
