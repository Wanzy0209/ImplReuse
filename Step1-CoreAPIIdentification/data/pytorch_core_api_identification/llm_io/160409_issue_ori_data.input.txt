Bug Report:
Title: test_flex_attention fails for float16 & bfloat16 dtypes on GPU
Issue ID: 160409
Original bug description: ### 🐛 Describe the bug

When running `inductor/test_flex_attention.py` on H100 GPUs I see test failures for 

```
TestFlexAttention.test_builtin_score_mods_different_block_size_bfloat16_score_mod5_BLOCK_SIZE2
TestFlexAttention.test_builtin_score_mods_different_block_size_bfloat16_score_mod5_BLOCK_SIZE_256
TestFlexAttention.test_builtin_score_mods_different_block_size_bfloat16_score_mod5_BLOCK_SIZE3
TestFlexAttention.test_builtin_score_mods_different_block_size_bfloat16_score_mod7_BLOCK_SIZE2
TestFlexAttention.test_builtin_score_mods_different_block_size_float16_score_mod5_BLOCK_SIZE2
TestFlexAttention.test_builtin_score_mods_different_block_size_float16_score_mod5_BLOCK_SIZE_256
TestFlexAttention.test_builtin_score_mods_different_block_size_float16_score_mod5_BLOCK_SIZE3
TestFlexAttention.test_builtin_score_mods_different_block_size_float16_score_mod7_BLOCK_SIZE2
TestFlexAttention.test_builtin_score_mods_different_seqlen_float16_score_mod2
TestFlexAttention.test_builtin_score_mods_different_seqlen_float16_score_mod5
TestFlexAttention.test_kv_batch_broadcast_float16_batch_dims1_head_dims0_score_mod5
TestFlexAttention.test_load_from_bias_seq_batch_float16
```

They seem to disappear  when run individually which hints to a RNG-related issue generating "unlucky" values, or some cached state. In neither case it seems good that the tests fail.

I can reproduce it with `python inductor/test_flex_attention.py -k test_builtin_score_mods_different_block_size_float16_score_` which shows the 4 failures out of 32 tests

The errors are rather large:

> AssertionError: False is not true : Grad_Query Compiled error 0.3025934650373362 is greater than ref error 0.00018538643547876397 by more than 1.1X.

It looks a bit weird that for lower precision types the factor is lower: https://github.com/pytorch/pytorch/blob/4d5b3f2d5af7c8e4f41da4ffca53fafe8bb86235/test/inductor/test_flex_attention.py#L464-L467

But even with the 10x the tests wouldn't pass

Some tests even abort in `compiled_out.backward(backward_grad)` with
> RuntimeError: Triton Error [CUDA]: an illegal memory access was encountered


### Versions

PyTorch 2.7.1 with CUDA 12.6 on 4 H100 GPUs
