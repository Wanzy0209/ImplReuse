Bug Report:
Title: Feedback about Broadcasting semantics
Issue ID: 162116
Original bug description: There is the following issue on this page: https://docs.pytorch.org/docs/stable/notes/broadcasting.html#broadcasting-semantics

The docs state that one precondition is, "Each tensor has at least one dimension."  Here's the example given:
```
>>> x=torch.empty((0,))
>>> y=torch.empty(2,2)
# x and y are not broadcastable, because x does not have at least 1 dimension
```

However, x does have one dimension.  That dimension is of size zero.  It's not failing the "at least one dimension" test; it's failing the "dimensions must be equal, 1, or do not exist" test.

Indeed, broadcasting does seem to work with tensors with no dimensions:

```
>>> x = torch.tensor((0,0,0,0,0))
>>> assert x.shape == (5,)
>>> y = torch.tensor(1)
>>> assert y.shape == ()
>>> torch.broadcast_tensors(x,y)
(tensor([0, 0, 0, 0, 0]), tensor([1, 1, 1, 1, 1]))

>>> x + y
tensor([1, 1, 1, 1, 1])
```

I would suggest that the bullet item about the precondition "Each tensor has at least one dimension." be removed, as it does not align with observable behavior.  The example can be removed, or its comments can be adjusted to note that the 0 dimension does not match the 2 dimension.
