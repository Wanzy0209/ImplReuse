Bug Report:
Title: torch.kthvaluelacks deterministic CUDA implementation (RuntimeError when determinism is enabled)
Issue ID: 165227
Original bug description: ### 🐛 Describe the bug

When `torch.use_deterministic_algorithms(True)` is enabled, calling an operation that internally uses `torch.kthvalue()` on CUDA throws:

RuntimeError: kthvalue CUDA does not have a deterministic implementation, but you set 'torch.use_deterministic_algorithms(True)'.

This occurs when using Brevitas quantization layers inside a YOLOv5 training setup. The issue appears to be that `torch.kthvalue` lacks a deterministic CUDA kernel.
