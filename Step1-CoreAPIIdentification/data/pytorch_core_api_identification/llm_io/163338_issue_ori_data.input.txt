Bug Report:
Title: Stable headers shouldn't have using declarations
Issue ID: 163338
Original bug description: ### 🐛 Describe the bug

One of the headers of the stable API contains a `using` declaration:
https://github.com/pytorch/pytorch/blob/33e6c5a93d4e249d3a05cbe434877b8a77922a90/torch/csrc/stable/ops.h#L13

This is generally [discouraged](https://google.github.io/styleguide/cppguide.html#Aliases) as it pollutes the global namespace of all downstream users.

Concretely, this caused me errors when I included the PyTorch headers before the CUTLASS ones, with failures such as these:
```
/home/lw/xformers/third_party/cutlass/include/cutlass/epilogue/collective/default_epilogue.hpp(202): error: "Tensor" is ambiguous
      Tensor tCgC = thr_mma.partition_C(gC);
      ^
```
