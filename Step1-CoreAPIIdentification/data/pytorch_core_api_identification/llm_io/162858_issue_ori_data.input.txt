Issue ID: 162858
Original bug description: Log the last k (k = 50?) bytecode instructions traced, along with the state of the symbolic Python stack.

i.e. print the last k outputs of `TORCH_LOGS=trace_bytecode` when logging a graph break.

For example,
```python

@torch.compile(backend="eager")
def fn(x):

    z = x + y

```
