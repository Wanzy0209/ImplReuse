Bug Report:
Title: Multiple definitions error when including <torch/csrc/stable/tensor.h> in extension with both CPU and CUDA
Issue ID: 164742
Original bug description: ### 🐛 Describe the bug

I’m quite excited about the new stable ABI and am porting a custom extension to it.
I followed the [libtorch_agnostic](https://github.com/pytorch/pytorch/blob/main/test/cpp_extensions/libtorch_agnostic_extension/libtorch_agnostic/csrc/kernel.cpp) test and attempted to include `<torch/csrc/stable/tensor.h>`.
When I include that header in both CPU and CUDA sources in the same extension, the link fails with a multiple definitions error for `torch::stable::Tensor::scalar_type() const`:
```
...
/usr/bin/ld: /.../src/example/example.o: in function `void std::__detail::__to_chars_10_impl<unsigned int>(char*, unsigned int, unsigned int)': 
/.../site-packages/torch/include/torch/csrc/stable/tensor_inl.h:17: multiple definition of `torch::stable::Tensor::scalar_type() const';
/.../build/temp.linux-x86_64-cpython-313/src/example/cuda/example.o:tmpxft_00011dfa_00000000-6_example.compute_90.cudafe1.cpp:(.text+0x16c): first defined here
collect2: error: ld returned 1 exit status
...
```
This does not happen if I include it in only one of the sources, or if I include `<torch/csrc/stable/tensor_struct.h>` instead.
Should `Tensor::scalar_type()` be marked inline?

Complete minimal reproducer in the block below.

`src/example/example.cpp`
```cpp
#include <Python.h>
#include <torch/csrc/stable/library.h>
#include <torch/csrc/stable/tensor.h>


extern "C" {
/* Creates a dummy empty _C module that can be imported from Python.
   The import from Python will load the .so consisting of this file
   in this extension, so that the STABLE_TORCH_LIBRARY static initializers
   below are run. */
PyObject* PyInit__C(void) {
  static struct PyModuleDef module_def = {
      PyModuleDef_HEAD_INIT,
      "_C", /* name of module */
      NULL, /* module documentation, may be NULL */
      -1, /* size of per-interpreter state of the module,
             or -1 if the module keeps state in global variables. */
      NULL, /* methods */
  };
  return PyModule_Create(&module_def);
}
}

namespace example {

torch::stable::Tensor myops(const torch::stable::Tensor x) {
  return x;
}

void boxed_myops(StableIValue* stack, uint64_t num_args, uint64_t num_outputs) {
  stack[0] = from(myops(to<torch::stable::Tensor>(stack[0])));
}

STABLE_TORCH_LIBRARY(example, m) {
  m.def("myops(Tensor x) -> Tensor");
}

STABLE_TORCH_LIBRARY_IMPL(example, CPU, m) {
  m.impl("myops", &boxed_myops);
}

} // namespace example
```
