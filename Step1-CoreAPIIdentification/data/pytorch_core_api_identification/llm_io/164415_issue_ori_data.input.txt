Bug Report:
Title: Support printing large tensors in MPS
Issue ID: 164415
Original bug description: ```
>>> import torch
>>> a = torch.ones((2, 1<<31), dtype=torch.int8, device='mps')
>>> print(a)
...
RuntimeError: MPSGaph does not support tensor dims larger than INT_MAX
```

The proposed solution is to add an alternate MPS implementation of `torch.cat` to use when the input is too large to use the MPSGraph implementation.
