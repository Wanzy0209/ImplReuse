Bug Report:
Title: Mypy type checking errors: PyTreeSpec inheritance
Issue ID: 160650
Original bug description: ### 🐛 Describe the bug

Running mypy on PyTorch codebase produces type checking errors that prevent clean validation in development and CI environments.

**Errors encountered:**

1. `torch/utils/_cxx_pytree.py:1014:1: error: Cannot inherit from final class "PyTreeSpec" [misc]`
   - `PyTreeSpec` (imported from optree) is marked as `@final` in optree's type stubs, but PyTorch's `LeafSpec` class inherits from it

**To reproduce:**

```bash
# Install mypy
pip install mypy mypy-extensions

# Run mypy from PyTorch root directory
mypy

# Output:
torch/utils/_cxx_pytree.py:1014:1: error: Cannot inherit from final class "PyTreeSpec"  [misc]
Found 1 error in 1 file (checked 1935 source files)
```
