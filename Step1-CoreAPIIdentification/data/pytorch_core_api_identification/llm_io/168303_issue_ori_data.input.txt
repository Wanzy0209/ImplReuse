Bug Report:
Title: Inductor codegen is missing support for CPPScheduling
Issue ID: 168303
Original bug description: ### 🐛 Describe the bug

When running with vLLM + torch 2.9.0 cpu builds we have seen that on both AArch64 and x86 from torch 2.9.0 onwards, in the inductor node list we see ForeachKernelSchedulerNode being used instead of OuterLoopFusedSchedulerNode. ForeachKernelSchedulerNode triggers the assert since it only has support SIMDScheduling and CUDACombinedScheduling when the backed for some ops that are part of the foreach is CPPScheduling.

Issue raised in vLLM: https://github.com/vllm-project/vllm/issues/28982#issuecomment-3559782580
