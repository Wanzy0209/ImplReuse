I have a code that is supposed to compute rolling multiple linear regression in pytorch. When I run this code on cpu, the results are very close to results from numpy.linalg.lstsq. However when I run the code on MPS, the result is completely wrong. 

example for 4 dimensional input
```
numpy: [1.00035739, 0.29986116, 0.19779432, 0.46009004]
cpu: [1.00035691, 0.29986125, 0.19779432, 0.46008980]
mps: [ 2.56928920e+07,  4.40364003e+14, -4.40364037e+14,  1.34075220e+07]
```

Here is a snippet of relevant part of function:

`
    # Reshape for batch matrix multiplication
    # x_conv: [B, D, N] -> [B, N, D, 1]
    x_expanded = (x*mask).unsqueeze(3)  # [B, N, D, 1]
    x_expanded_T = x_expanded.transpose(2, 3)            # [B, N, 1, D]

    # Batch matrix multiply: [B, N, D, 1] @ [B, N, 1, D] -> [B, N, D, D]
    # only last two dims are matrix-multiplied
    XTX = torch.matmul(x_expanded, x_expanded_T)      # [B, N, D, D]

    #we need to convolve each element of [D, D] matrix with fitler
    # Reshape XTX from [B, N, D, D] to [B, D*D, N] for convolution
    # Each element of the D×D matrix becomes a separate channel
    XTX_flat = XTX.permute(0, 2, 3, 1).reshape(B, D * D, N)  # [B, D*D, N]

    # Apply convolution to sum over windows
    XTX_conv = F.conv1d(XTX_flat, filters_XTX, groups=1)  # [B, D*D, out_len]

    # Reshape back to [B, out_len, D, D]
    XTX_conv = XTX_conv.reshape(B, D, D, out_len).permute(0, 3, 1, 2)  # [B, out_len, D, D]

    #inverse of x.T x
    XTX_inv = torch.linalg.inv(XTX_conv)                       # [B, out_len, D, D]
`

I have traced the function, and while XTX_conv has mismatch between cpu and mps on order of 1e-7, the computation completely breaks down when computing inverse. The matrix that is being inverted has full rank, but the computation seems to explode on mps.
