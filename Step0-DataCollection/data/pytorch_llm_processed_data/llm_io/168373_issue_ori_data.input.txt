Consider this code where a fresh backend function is created on every instance of `torch.compile` call. This leads to a recompilation issue because `torch.compile` guards on the backend function to check if it can reuse the previously compiled artifact. This is **intentional** because if user want to use two different backends, we want to give two different compiled artifacts. 

However, in this example this seems accidental on the user side. So, this issue gives you a workaround. 

```
import torch
from torch._dynamo.backends.common import aot_autograd
from functorch.compile import nop


def torch_compile_with_custom_backend(
    module: torch.nn.Module,
):
    opt_layer = torch.compile(
        module, backend=aot_autograd(fw_compiler=nop, bw_compiler=nop), fullgraph=True
    )

    return opt_layer


class SubMod(torch.nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, x):
        return torch.sin(x)


class Mod(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.mod_a = SubMod()
        self.mod_b = SubMod()

        self.mod_a = torch_compile_with_custom_backend(self.mod_a)
        self.mod_b = torch_compile_with_custom_backend(self.mod_b)

    def forward(self, x):
        return self.mod_a(x) + self.mod_b(x)


mod = Mod()
x = torch.randn(4)
mod(x)
```

After PR https://github.com/pytorch/pytorch/pull/168387 - you will see this type of recompilation message
```
BACKEND_MATCH failure: torch.compile detected different backend callables. If this is unexpected, wrap your backend in functools.partial (or reuse the same cached backend) to avoid creating a new backend function each time. More details: https://github.com/pytorch/pytorch/issues/168373
```


**Workaround** - In the above example, the fresh creation of backend function seems accidental. We can fix it by using functools partial. 

```
import torch
from torch._dynamo.backends.common import aot_autograd
from functorch.compile import nop
import functools


@functools.lru_cache
def get_backend(fw_compiler, bw_compiler):
    return aot_autograd(fw_compiler=nop, bw_compiler=nop)


def torch_compile_with_custom_backend(
    module: torch.nn.Module,
):
    opt_layer = torch.compile(module, backend=get_backend(nop, nop), fullgraph=True)

    return opt_layer


class SubMod(torch.nn.Module):
    def __init__(self):
        super().__init__()

    def forward(self, x):
        return torch.sin(x)


class Mod(torch.nn.Module):
    def __init__(self):
        super().__init__()
        self.mod_a = SubMod()
        self.mod_b = SubMod()

        self.mod_a = torch_compile_with_custom_backend(self.mod_a)
        self.mod_b = torch_compile_with_custom_backend(self.mod_b)

    def forward(self, x):
        return self.mod_a(x) + self.mod_b(x)


mod = Mod()
x = torch.randn(4)
mod(x)

```
