**Title**: torch.bmm+torch.compileno longer works in 2.9, but worked in 2.8

**Issue ID**: 165892

**Bug Description**: The issue describes that `torch.bmm` with `torch.compile` no longer works in PyTorch 2.9, but it worked in 2.8. The error occurs when using `out_dtype` parameter with `torch.bmm` inside a compiled function.

**Repro Code**:
```python
import torch

A = torch.rand((1, 1024, 1024), device="cuda", dtype=torch.float16)
B = torch.rand((1, 1024, 1024), device="cuda", dtype=torch.float16)

@torch.compile
def linear(weight, input):
    return torch.bmm(input, weight, out_dtype=torch.float32)

linear(A, B)
```

**Repro Output**: The error message shows:
```
torch._inductor.exc.InductorError: LoweringException: AssertionError: out_dtype is not supported for Triton
  target: aten.bmm.dtype
  args[0]: TensorBox(StorageBox(
    InputBuffer(name='arg0_1', layout=FixedLayout('cuda:0', torch.float16, size=[1, 1024, 1024], stride=[1048576, 1024, 1]))
  ))
  args[1]: TensorBox(StorageBox(
    InputBuffer(name='arg1_1', layout=FixedLayout('cuda:0', torch.float16, size=[1, 1024, 1024], stride=[1048576, 1024, 1]))
  ))
  args[2]: torch.float32
```

**Trigger Conditions**:
- Backend: CUDA (device="cuda")
- dtype: torch.float16 (input), torch.float32 (output via out_dtype)


- Input shape: (1, 1024, 1024)
- Other conditions: Using torch.compile with torch.bmm and out_dtype parameter

**Affected API**: torch.bmm (specifically with out_dtype parameter inside torch.compile)

**Environment**:
- PyTorch version: 2.9.0
- Python version: 3.10.12
- OS: Ubuntu 22.04.5 LTS (x86_64)
- Hardware: NVIDIA H100 80GB HBM3
