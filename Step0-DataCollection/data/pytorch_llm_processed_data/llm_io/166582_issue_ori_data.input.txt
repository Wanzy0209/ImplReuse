I discovered the bug when building a custom Torch compiler backend for a custom AI ASIC, and ran it on a simulated hardware platform.

The structure is meant to be simple, as the backend replaces `nn.Linear` calls with matmuls through my own chip.
However, the complex part is that the chip is super small and can only do `int8` matmuls, with `int16` output, so there is some quantization lowering that appears to be breaking, as I am training the model for the chip using Quantization Aware Training (QAT).

Previously, I used legacy torch `QuantStub` and `DeQuantStub` but have now used TorchAO to manage the QAT workflow with an XNNPack quantizer backend. Both approaches have encountered this issue.

To reproduce, register a backend like:
```python
import torch
import torch._dynamo
from test_tpu import matmul
from torch._inductor.compile_fx import compile_fx
from torch._dynamo import register_backend, disable
import numpy as np
import asyncio

@disable
async def dut_matmul_async(dut, a: torch.Tensor, b: torch.Tensor, bias=None):
    # Now safe to quantize
    a_q = a.clamp(-128, 127).to(torch.int8)
    b_q = b.clamp(-128, 127).to(torch.int8)

    c = await matmul(dut, a_q, b_q, transpose=True, is_torch=True)
    if bias is not None:
        c = c + bias.round().to(torch.int32)
    return c.to(torch.int32)

def dut_matmul_sync(dut, a, b, bias=None):
    """Synchronous wrapper – torch.compile expects a normal function."""
    return asyncio.run(dut_matmul_async(dut, a, b, bias))

def make_backend(dut):
    """
    Returns a *registered* backend that has the DUT baked in.
    The FX graph is the first argument.
    """
    @register_backend(name=f"tpu_net")
    def _backend(gm: torch.fx.GraphModule, example_inputs):
        print("\n=== FX graph received ===")
        gm.graph.print_tabular()

        # ---- replace every linear ----
        for node in list(gm.graph.nodes):
            if node.target == torch.ops.aten.linear.default:
                x, weight, bias = node.args
                with gm.graph.inserting_before(node):
                    new_node = gm.graph.call_function(
                        dut_matmul_sync,
                        args=(dut, x, weight, bias),
                    )
                    node.replace_all_uses_with(new_node)
                    gm.graph.erase_node(node)

        gm.recompile()
        print("\n=== Modified graph ===")
        gm.graph.print_tabular()

        # Let Inductor compile the rest
        return compile_fx(gm, example_inputs)

    return _backend
```
