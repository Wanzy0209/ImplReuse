**Title**: [CUDA][Triton][PTXAS] Triton Wheel Missing CUDA13 PTXAS - Breakage exists for the environment where CTK is not present

**Issue ID**: 163801

**Bug Description**: The issue describes that Triton release/3.5x ships a PTXAS version based on CUDA12.8 by default. In environments where the latest CTK (CUDA Toolkit) is NOT installed, this causes problems:
- CUDA12.8 ptxas cannot handle THOR device (sm_110a)
- CUDA12.8 ptxas cannot handle SM_121 device (sm_121a)

Users on THOR encounter: `ptxas fatal : Value 'sm_110a' is not defined for option 'gpu-name'`
Users on SM_121 device encounter: `ptxas fatal : Value 'sm_121a' is not defined for option 'gpu-name'`

In environments with the latest CTK installed, users may need to explicitly set `export TRITON_PTXAS_PATH=/usr/local/cuda/bin/ptxas` to get the right ptxas.
