The current [type signature of `torch.nn.Module.__setattr__()`](https://github.com/pytorch/pytorch/blob/main/torch/nn/modules/module.py#L1976C38-L1976C68) claims that the method only accepts `Tensor | Module` as a value. However, the implementation [forwards all other values to `super().__setattr__()`](https://github.com/pytorch/pytorch/blob/main/torch/nn/modules/module.py#L2079C21-L2079C41) and therefore accepts any value type as input.

This behavior confuses type checkers (confirmed with `ty 0.0.1-alpha.25`, see MRE below). Would it be possible to accept `value: Union[Tensor, "Module", Any]` instead?

I understand that the return type of `__getattr__` must not be `Any`. But does this also apply to the input type of `__setattr__`?
