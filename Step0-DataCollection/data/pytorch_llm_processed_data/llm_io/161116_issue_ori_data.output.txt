**Title**: NCCL Segfault when initializing a process group on an NVL72

**Issue ID**: 161116

**Bug Description**: The user is trying to run distributed training with Torchtitan on a GB200 NVL72 cluster. Using more than 10 trays (40 GPUs) fails with an NCCL segmentation fault, while using 10 or fewer trays works fine. The issue occurs during process group creation. The error log shows a segmentation fault in `ncclTopoSearchRecGpu` function. After recompiling NCCL with debug symbols, it appears to be a stack overflow issue (0x0 addresses and all threads being in `ncclTopoSearchRecGpu`). The user has verified that `ulimit -s` is set to unlimited.

**Repro Code**:
```python
import torch
import torch.distributed as dist
import os
def main():
    gpu_id = int(os.environ["LOCAL_RANK"])
    
    device = f"cuda:{gpu_id}"
    torch.cuda.set_device(device)
    dist.init_process_group(backend='nccl',
                            device_id=gpu_id,
                            )
    dist.barrier()
    
if __name__ == "__main__":
    main()
```
