**Problem:**
PyTorch 2.8.0 ONNX export incorrectly generates boolean `True` instead of integer `1` for the `allowzero` attribute in Reshape operations, causing downstream serialization failures with onnx-ir.

**Minimal reproducing example:**
```python
#!/usr/bin/env python3
import torch
import torch.nn as nn
import warnings
import tempfile
import os

# CRITICAL: Force DeprecationWarnings to be errors (this triggers the issue!)
warnings.filterwarnings("error", category=DeprecationWarning)

class TestModel(nn.Module):
    def forward(self, x):
        # This reshape triggers the boolean->int issue
        return x.reshape(1, -1)

model = TestModel().eval()
x = torch.randn(2, 4)

# Try ONNX export - this should trigger SerdeError
with tempfile.NamedTemporaryFile(suffix='.onnx', delete=False) as f:
    try:
        torch.onnx.export(
            model,
            (x,),
            f.name,
            opset_version=18,
            dynamo=True,
            verbose=False
        )
        print("❌ UNEXPECTED: Export succeeded")
    except Exception as e:
        print(f"✅ CONFIRMED: {type(e).__name__}: {e}")
    finally:
        try:
            os.unlink(f.name)
        except:
            pass
```

**Error:**
```
onnx_ir.serde.SerdeError: Error calling serialize_attribute_into with: Attr('allowzero', INT, True)
```

**Environment:**
- **PyTorch**: 2.8.0+cpu
- **ONNX**: 1.19.0  
- **onnx-ir**: 0.1.7
- **Platform**: Linux (Ubuntu 22.04)
- **Python**: 3.11.0rc1
- **Protobuf**: 6.32.0

**Root Cause:**
PyTorch's new dynamo-based ONNX export generates `Attr('allowzero', INT, True)` instead of the ONNX-compliant `Attr('allowzero', INT, 1)`. The ONNX specification requires integer values (0/1) for the allowzero attribute.

**Impact:**
- Breaks ONNX export for PyTorch Geometric models in CI environments
- Affects any model using reshape operations with strict warning handling
- Forces workarounds in downstream projects

**Expected Behavior:**
`allowzero=True` should serialize as `Attr('allowzero', INT, 1)`

**Actual Behavior:**
`allowzero=True` serializes as `Attr('allowzero', INT, True)` (boolean in integer field)
