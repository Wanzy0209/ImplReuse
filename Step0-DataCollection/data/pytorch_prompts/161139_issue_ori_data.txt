When setting `PYTORCH_CUDA_ALLOC_CONF` to `roundup_power2_divisions:[>:1]` PyTorch doesn't round up requested memory to the nearest power of two. Instead it works as this parameter wasn't set at all and rounds to the nearest 512 bytes. This logic is clearly [seen here](https://github.com/pytorch/pytorch/blob/67b98da1b262317f9c0375d64a4b467c82712548/c10/cuda/CUDACachingAllocator.cpp#L2198-L2203)

If you run this code
```
import os
os.environ["PYTORCH_CUDA_ALLOC_CONF"] = "roundup_power2_divisions:[>:1]"

import torch

MB = 1024 * 1024
t = torch.empty([514*MB], dtype=torch.int8, device='cuda')

print(torch.cuda.memory_summary())
```

you will see, that reserved memory is ~525 MiB instead of 1024 MiB.

If you change `PYTORCH_CUDA_ALLOC_CONF` to `roundup_power2_divisions:[>:2]`, you will see clear 768 MiB in memory summary
