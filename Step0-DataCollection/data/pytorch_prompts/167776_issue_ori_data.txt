It would be nice if we could register patterns/replacement using class instances, and pass the instance method reference (`instance.method`) to the `register_replacement` function, like below. This way we can abstract some of the common code away and make pattern registration as simple as possible.

Note that the scalar in the example could likely be handled by `scalar_workaround`, but there are other cases in vLLM where we have to access pattern class instances for scalars, common sub-patterns, etc.
