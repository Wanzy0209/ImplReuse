When taking gradients with ``torch.autograd.grad`` and ``allow_unused=True``, the resulting gradient sometimes has ``requires_grad=True`` and sometimes does not, depending on whether the input tensor was actually used in the graph. This is despite create and retain graph both being set to ``False``:

```python
x = torch.ones(10).requires_grad_(True)
y = torch.ones(10).requires_grad_(True)
z = (x**2).sum()
g = torch.autograd.grad(z, (x, y), allow_unused=True, materialize_grads=True, retain_graph=False, create_graph=False)

g[0].requires_grad # False, expected
g[1].requires_grad # True, unexpected
```
