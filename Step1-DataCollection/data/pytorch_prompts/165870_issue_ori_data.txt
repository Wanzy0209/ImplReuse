Follow up from https://github.com/pytorch/pytorch/pull/165254#issuecomment-3408776145.

`lu_factor` on a singular matrix should result in an error like it does on the CPU, but currently does not:
```python
import torch

t = torch.tensor([[1.0, 2.0], [2.0, 4.0]], device="mps")
torch.linalg.lu_factor(t)
```

On the CPU:
> RuntimeError: torch.linalg.lu_factor: U[2,2] is zero and using it on lu_solve would result in a division by zero. If you still want to perform the factorization, consider calling linalg.lu(A, pivot) or linalg.lu_factor_ex(A, pivot)
