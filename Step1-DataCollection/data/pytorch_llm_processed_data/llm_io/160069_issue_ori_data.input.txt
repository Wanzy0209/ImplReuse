## Requirements

1. `torch.cuda.empty_cache()` supports the `torch.cuda.MemPool` as optional argument. The default value is the default memory pool. Similar to the C++ interface [`c10::cuda::CUDACachingAllocator::emptyCache`](https://github.com/pytorch/pytorch/blob/aa75e917bdb0f95bb6dee81853c2d3c4ab3e1883/c10/cuda/CUDACachingAllocator.h#L367)
2. Provide an new interface to clear the cache for all the memory pools.

## Current Behavior

The [`torch.cuda.empty_cache()`](https://github.com/pytorch/pytorch/blob/aa75e917bdb0f95bb6dee81853c2d3c4ab3e1883/torch/cuda/memory.py#L212) currently ONLY clears the cache of the "default memory pool", but leaves the other memory pools uncleared.

Correction: `torch.cuda.empty_cache()` clears all memory that is safe to clear. The current design of mempool makes it so that as long as mempool object is alive, its memory is not supposed to be cleared. In the example below, if you delete mpool object, `torch.cuda.empty_cache()` clears all the memory. Please see the documentation for the mem pool linked in the comment, "To reclaim memory, users will first need to ensure nothing is using the pool. When none of the tensors are holding a reference to the pool, empty_cache() will be called internally on deletion of the pool, hence returning all the memory to the system."

Below is an example that allocate 1GB memory in the default memory pool and the customized memory pool. After `torch.cuda.empty_cache()`, only the memory in the default memory pool is returned to the system.

```py
import torch

GB = 1024*1024*1024
device = torch.device('cuda')


def dump_mem():
    free, total = torch.cuda.mem_get_info()
    print(f"free: {free / (GB):.2f} GiB, total: {total / (GB):.2f} GiB")


def alloc_1gb():
    return torch.empty((GB,), dtype=torch.int8, device=device)


print("before allocation")
dump_mem()

t0 = alloc_1gb()
print("t0 allocated")
dump_mem()

mpool = torch.cuda.MemPool()
with torch.cuda.use_mem_pool(mpool):
    t1 = alloc_1gb()
    print("t1 allocated")
    dump_mem()

t0 = None
t1 = None
print("t0 and t1 freed")
dump_mem()
torch.cuda.empty_cache()
print("cache emptied")
dump_mem()
```
