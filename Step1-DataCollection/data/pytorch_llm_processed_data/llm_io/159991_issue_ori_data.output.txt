**Title**: [DTensor] Decide / Document RNG semantics

**Issue ID**: 159991

**Bug Description**: This is actually a design question/discussion rather than a traditional bug report. The issue is about deciding the semantics of RNG (Random Number Generator) behavior in DTensor. Specifically, whether the state-offset advancement should be visible to the user when they pass their own RNG to DTensor random ops.

The key points are:
1. DTensor will utilize a 'generator' passed as kwarg to random ops instead of using its own built-in generator
2. The question is whether the passed-in RNG object should advance after being used
3. Currently, DTensor keeps an alternate copy of the original default RNG and only advances that copy
4. There are two problems identified:
   - Users need to call a hidden API `torch.distributed.tensor._random._rng_tracker._manual_seed` to affect DTensor's RNG state after init
   - Re-seeding the passed-in RNG object is ineffective

**Repro Code**: There is a test example provided in the issue:
```python
def test_init_with_user_generator(self):
    device_mesh = self.build_device_mesh()
    torch.manual_seed(42)
    rng = torch.Generator(device="cuda").manual_seed(42)
    t1 = torch.distributed.tensor.empty(
        (2, 3), device_mesh=device_mesh, placements=[Shard(0)]
    )
    t2 = torch.distributed.tensor.empty(
        (2, 3), device_mesh=device_mesh, placements=[Shard(0)]
    )
    for i in range(2):
        print(f"{i=}")
        # run a second time, to make sure that `rng`'s offset-state is advancing on the second usage
        torch.nn.init.uniform_(t1, 0.0, 1.0)
        torch.nn.init.uniform_(t2, 0.0, 1.0, rng)
        self.assertEqual(t1.full_tensor(), t2.full_tensor(), f"Failed at {i=}")

    # Problem area:
    # (1)
    # torch.distributed.tensor._random._rng_tracker._manual_seed(55)
    # torch.manual_seed(55)
    # (2)
    # rng.manual_seed(55)
    torch.nn.init.uniform_(t1, 0.0, 1.0)
    torch.nn.init.uniform_(t2, 0.0, 1.0, rng)
    self.assertEqual(t1.full_tensor(), t2.full_tensor())
```
