**Title**: LBFGS always raises warning about converting a tensor with requires_grad=True to a scalar?

**Issue ID**: 160197

**Bug Description**: The user reports that with torch version 2.8.0, converting a tensor with `requires_grad=True` to a scalar now raises a `UserWarning`. This warning is always raised when using a closure function with LBFGS because LBFGS calls `float(closure())`. The user asks if this is expected behavior and how to avoid this warning.

**Repro Code**: The user provides a minimal example:
```python
import warnings
warnings.simplefilter('error')
import torch
print(torch.__version__)
a, b = torch.rand((2, 32, 32))
a.requires_grad_()
optimizer = torch.optim.LBFGS([a])
loss_fn = lambda x, y: (x-y).pow(2).mean()

def closure():
    optimizer.zero_grad()
    loss = loss_fn(a, b)
    loss.backward()
    return loss

for i in range(100):
    optimizer.step(closure)
    print(i, loss_fn(a, b))
```

**Repro Output**: The warning gets raised (and with `warnings.simplefilter('error')`, it would cause an error).
