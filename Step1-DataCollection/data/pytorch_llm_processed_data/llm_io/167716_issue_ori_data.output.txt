**Title**: torch.sparse.mmreturns corrupted sparse tensor causing Segmentation fault into_dense()on PyTorch 2.9.0

**Issue ID**: 167716

**Bug Description**: The user is experiencing a segmentation fault when using `torch.sparse.mm()` with two sparse matrices and then calling `to_dense()` on the result. The issue is that the sparse matrix multiplication operation completes without errors, but attempting to convert the result to a dense matrix causes a segmentation fault. Interestingly, printing the matrices before the multiplication resolves the issue, suggesting an initialization problem. The user also found that the index data of the resulting matrix C appears to be corrupted.

**Repro Code**:
```python
import torch

torch.manual_seed(42)

indices_A = torch.tensor([[0, 1, 2], [0, 2, 3]])  
values_A = torch.tensor([1.0, 2.0, 3.0])        
A = torch.sparse_coo_tensor(indices_A, values_A, size=(3, 4))

indices_B = torch.tensor([[0, 1, 2, 3], [0, 1, 1, 2]])  
values_B = torch.tensor([4.0, 5.0, 6.0, 7.0]) 
B = torch.sparse_coo_tensor(indices_B, values_B, size=(4, 2))

C = torch.sparse.mm(A, B)
C = C.to_dense()
```
