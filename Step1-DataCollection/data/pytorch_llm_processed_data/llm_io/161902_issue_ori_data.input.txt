When providing invalid or conflicting `dynamic_shapes` specifications to `torch.export`, the system crashes with an internal `AttributeError`:

```
AttributeError: 'One' object has no attribute 'name'
```
This occurs when arithmetic expressions involving Dim are not supported (e.g. `2 * Dim("d")`, `Dim("d") + 1`).

Expected behavior: Raise a user-friendly error (e.g., "`Unsupported arithmetic expression in dynamic_shapes`") rather than an internal AttributeError.

Minimal Reproduction Script

```python
import torch
import torch.nn as nn
from torch.export import export, Dim

class Add(nn.Module):
    def forward(self, x, y):
        return x + y

m = Add()
x = torch.randn(2, 3, requires_grad=True)
y = torch.randn(2, 3, requires_grad=True)

# Intentionally conflicting/unsupported dynamic shapes
conflicting = [
    {0: 2 * Dim("d")},   # invalid arithmetic
    {0: Dim("d") + 1},   # unsupported expression
]

# Expected: clear error message
# Actual: AttributeError: 'One' object has no attribute 'name'
export(m, (x, y), dynamic_shapes=conflicting)
```
