    - bug_description: ### 🐛 Describe the bug

When running `torch.fx.passes.fake_tensor_prop.FakeTensorProp` on a graph containing `aten.polar` with dynamic  shapes, the output shapes become concretized to the example input sizes. This is unexpected—symbolic dims should be preserved. This appears to stem from `aten.polar`’s fake/meta behavior. Reverting the change introduced in https://github.com/pytorch/pytorch/pull/160894
 fixes the issue.

**Minimal repo:**

```
import torch
import torch.nn as nn

from torch.export import export, Dim
from torch.fx import GraphModule
from torch.fx.passes.fake_tensor_prop import FakeTensorProp
from torch._export.utils import _detect_fake_mode_from_gm

class PolarToy(nn.Module):
    def __init__(self, head_dim: int = 32):
        super().__init__()
        self.head_dim = head_dim

    def forward(self, x):
        freqs = x.tanh()
        ones_like = torch.ones_like(freqs)
        freqs_cis = torch.polar(ones_like, freqs)
        return freqs_cis.real + freqs_cis.imag


def export_with_2d_dynamic_batch(mod: nn.Module, device: str = "cpu") -> GraphModule:
    mod = mod.to(device).eval()
    sample = torch.randn(2, 3, 32, device=device)
    dynamic_shapes = ({0: Dim("s0", min=1, max=1024), 1: Dim("s1", min=1, max=2048)},)
    ep = export(mod, (sample,), dynamic_shapes=dynamic_shapes, strict=False)
    gm = ep.module() if hasattr(ep, "module") else ep
    if not isinstance(gm, GraphModule):
        raise RuntimeError("Expected a GraphModule from export().")
    return gm


def main():
    device = "cpu"
    hidden = 7
    mod = PolarToy(hidden)
    gm = export_with_2d_dynamic_batch(mod, device=device)
    gm.print_readable()

    inps = [node.meta.get("val") for node in gm.graph.nodes if node.op == "placeholder"]
    fake_mode = _detect_fake_mode_from_gm(gm)
    FakeTensorProp(gm, fake_mode).propagate(*inps)
    gm.print_readable()


if __name__ == "__main__":
    main()

```

**Observed output**

Before FakeTensorProp :
```
tanh:      "f32[s77, s27, 32]" = aten.tanh.default(x)
ones_like: "f32[s77, s27, 32]" = aten.ones_like.default(tanh, pin_memory = False)
polar:     "c64[s77, s27, 32]" = aten.polar.default(ones_like, tanh)
```
After FakeTensorProp:

```
tanh:      "f32[2, 3, 32]" = aten.tanh.default(x)
ones_like: "f32[2, 3, 32]" = aten.ones_like.default(tanh, pin_memory = False)
polar:     "c64[2, 3, 32]" = aten.polar.default(ones_like, tanh)
```

Notably, the concretization starts at the aten.polar site and then propagates.
