**Title**: torch.jit.script crashes on Python 3.14 in PyTorch 2.9.1 (__annotations__missing)

**Error Description**: The bug is that calling `torch.jit.script` on a trivial `nn.Module` crashes immediately on Python 3.14 with an AttributeError. The error message is: `'JITCrash' object has no attribute '__annotations__'. Did you mean: '__annotate_func__'?`. The underlying cause is that TorchScript (in torch 2.9) assumes that every nn.Module instance has a __annotations__ attribute, which is not guaranteed on Python ≥ 3.14.
