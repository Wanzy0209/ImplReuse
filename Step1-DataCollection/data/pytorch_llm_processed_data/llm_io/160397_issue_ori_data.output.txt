**Title**: Documentation for torch.finfo().eps is incorrect.

**Issue ID**: 160397

**Bug Description**: The issue states that in `docs/source/type_info.md`, `torch.info().eps` is defined as "The smallest representable number such that `1.0 + eps != 1.0`." However, the actual value of `torch.finfo().eps` equals to the Unit in the Last Place (ULP), which is $u = 2^{-M}$ where $M$ is the bit-width of mantissa. The smallest representable number such that `1.0 + eps != 1.0` is not the ULP, but rather the smallest floating point number larger than $2^{-M-1} = u/2$, which is $\epsilon = (1 + 1/2^M) \times 2^{-M-1} = 2^{-M-1} + 2^{-2M-1}$.

**Repro Code**: The issue provides a Python code snippet that demonstrates the problem.
