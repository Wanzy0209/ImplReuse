**Title**: Use FP32 for ConvTranspose3D when using autocast on MPS

**Issue ID**: 160332

**Bug Description**: The issue describes that while MPS support for ConvTranspose3D was added for FP32 and Complex64 types, `amp.autocast` tries to use half-precision floats (BF16 or FP16) which is not supported on MPS. The user suggests marking ConvTranspose3D as requiring FP32 for autocast purposes when running on MPS until half-precision variants are supported.

**Repro Code**:
```python
import torch
from torch import nn

device = torch.device('mps')

with torch.amp.autocast(device_type=device.type):
    m = nn.ConvTranspose3d(16, 33, 3, stride=2)
    m.to(device)
    x = torch.randn(20, 16, 10, 50, 100).to(device)
    u = m(x)
```

**Repro Output**:
```
RuntimeError: ConvTranspose 3D with BF16 or FP16 types is not supported on MPS
```

**Trigger Conditions**:
- Backend: MPS
- Dtype: BF16 or FP16 (half-precision floats)
- Input shape: (20, 16, 10, 50, 100)
- Other conditions: Using `torch.amp.autocast` with device_type='mps'

**Affected API**: `nn.ConvTranspose3d` (or `F.conv_transpose3d`)

**Environment**:
- PyTorch version: 2.9.0.dev20250811
- Python version: 3.11.11
- OS: macOS 15.6 (arm64)
- Hardware: Apple M3 Max
