**Title**: NestedTensor: max_dim / min_dim not working for integer tensors

**Issue ID**: 162049

**Bug Description**: The issue describes that calling `.max(dim=...)`, `.min(dim=...)`, `.argmax(dim=...)`, or `.argmin(dim=...)` on a nested jagged tensor with integer datatype raises an error. These functions work for floating point types but not for integer types. The cause is that the implementation uses `torch.finfo` to determine the minimum value for the given type, but for integral types, `torch.iinfo` should be used instead.

**Repro Code**:
```python
import torch

x = torch.nested.nested_tensor(
    [torch.arange(0, n) for n in (10, 20, 30)],
    layout=torch.jagged,
)
print(x.max(dim=1).values)
```

**Repro Output**: The error is a TypeError:
```
TypeError: torch.finfo() requires a floating point input type. Use torch.iinfo to handle 'torch.finfo'
```

**Trigger Conditions**:
- Backend: Not explicitly mentioned
- dtype: Integer datatypes (the example uses `torch.arange` which creates int64 by default)
- Input shape: Nested jagged tensor with varying lengths (10, 20, 30)
- Other conditions: Using `.max(dim=...)`, `.min(dim=...)`, `.argmax(dim=...)`, or `.argmin(dim=...)` on nested jagged tensors

**Affected API**: 
- `torch.nested.nested_tensor(..., layout=torch.jagged).max(dim=...)`
- `torch.nested.nested_tensor(..., layout=torch.jagged).min(dim=...)`
- `torch.nested.nested_tensor(..., layout=torch.jagged).argmax(dim=...)`


- `torch.nested.nested_tensor(..., layout=torch.jagged).argmin(dim=...)`

- Hardware: NVIDIA GeForce RTX 5090, NVIDIA RTX A400
